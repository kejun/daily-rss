### 1. OpenAI GPT-5.6 正式发布：三尺寸模型全面上线

今天 AI 圈最重磅的消息莫过于 OpenAI 正式发布了 **GPT-5.6** 系列模型，包含三个尺寸：

- **GPT-5.6 Luna**（最小）：$1/$6 per 1M tokens，定位轻量级任务
- **GPT-5.6 Terra**（中等）：$2.50/$15 per 1M tokens，平衡性能与成本
- **GPT-5.6 Sol**（最大）：$5/$30 per 1M tokens，旗舰级模型

在 Agents' Last Exam 基准测试中（覆盖 55 个领域的长期专业工作流），GPT-5.6 Sol 取得 53.6 分的新高，超过 Claude Fable 5 达 13.1 分。值得注意的是，即使在中等推理级别下，它也超越 Fable 5 达 11.4 分，而成本仅约为后者的四分之一。更小的 Luna 和 Terra 模型也在约十六分之一成本下超越了 Fable 5。

GPT-5.6 还引入了多项新 API 特性：**程序化工具调用**（Programmatic Tool Calling）允许模型编排并运行 JavaScript 来协调工具调用；**多智能体**（Multi-agent）让模型可以启动子智能体进行并行工作；**提示词缓存断点**（Prompt Cache Breakpoints）将 Claude 的缓存模型引入 OpenAI API。

Simon Willison 在早期体验后表示 GPT-5.6 Sol "非常称职"，但在复杂编码任务上尚未让他感到明显优于 Anthropic 的 Fable 模型。有趣的是，OpenAI 在发布前一天专门发文指出 SWE-Bench Pro 存在约 30% 的破损任务——恰好在 Fable 5 大幅领先 GPT-5.6 系列的该基准上。

### 2. SpaceXAI 与 Cursor 联合发布 Grok 4.5：最强 Grok 登场

SpaceXAI（即 xAI）与 Cursor 联合训练发布了 **Grok 4.5**，这是 SpaceXAI 以 600 亿美元收购 Cursor 后的首个联合成果。

**关键指标：**
- 在编码、智能体和知识工作方面，性能与 Claude Opus 4.8 和 GPT 5.5 处于同一量级

Elon Musk 在 X 上将其定位为 "Opus 级模型，但更快、更高效、更便宜"，并表示下月将有更大的模型发布。考虑到 Cursor 的 Composer 模型也在编码领域持续进步，这笔 600 亿美元收购的协同效应正在双向显现。

### 3. OpenAI GPT-Live：全双工语音模型，边听边说

OpenAI 推出了 **GPT-Live**，一款全双工（full-duplex）语音模型，能够同时收听和说话，处理自然的对话提示（如打断、插话），并在维持对话流的同时将复杂任务委派给 GPT-5.5 处理。

这标志着语音交互从"你说完-它再说"的半双工模式，迈向真正的人类级自然对话。对于客服、陪伴、实时翻译等场景意义重大。

## 📰 行业深度阅读

### 📖 1. OpenAI 审查 SWE-Bench Pro：约 30% 任务存在缺陷

OpenAI 在发布 GPT-5.6 前一天发布了 [《Separating Signal from Noise: Coding Evaluations》](https://openai.com/index/separating-signal-from-noise-coding-evaluations/)，对 SWE-Bench Pro 的构建、模型失败模式和任务元数据进行了详细审查。

**核心发现：** 约 30% 的公开任务存在缺陷。这可能导致编码能力、安全性和模型进步的评估被扭曲。

**背景：** 在 SWE-Bench Pro 上，Claude Fable 5 得分 80%，而 GPT-5.6 Sol 仅 64.6%。OpenAI 在此时发布该审查报告，时机耐人寻味。

**启示：** 基准测试的可靠性正在成为 LLM 竞争中的关键战场。随着模型能力越来越接近，评估工具的准确性直接影响行业对"谁更强"的判断。

### 📖 2. Anthropic GRAM：双用途知识的"关闭开关"

[《An Off Switch for Dual-Use Knowledge in AI Models》](https://www.anthropic.com/research/off-switch-dual-use) 介绍了 Anthropic 最新的模型安全研究。

**核心思路：** GRAM（Gradient-Routed Auxiliary Modules）允许在单一模型成本下训练多个单独过滤的模型。为每类双用途知识提供专用的、可移除的隔间，仅在学习双用途数据时更新这些隔间。训练后可以删除模型的特定知识部分。

**意义：** 这为模型安全提供了比传统微调更强的框架。想象一下，可以让模型学会如何合成生物武器，然后在部署前精确删除这部分知识——而不影响模型的其他能力。

### 📖 3. 自进化智能体分类法：Agent 如何自我提升

Shilong Liu 在 [X 帖子](https://x.com/atasteoff/status/2074800880017342665) 中提出了一个自进化 Agent 分类框架：

1. **制品优化（Artifact Optimization）**：进化发生在输出层面——Agent 不断优化自己的产出
2. **Harness 自我改进（Harness Self-Improvement）**：进化发生在 Agent 基础设施层面——Agent 改进自己的工作流和工具
3. **模型学习（Model Learning）**：进化发生在模型权重层面——Agent 真正改变了自己的"大脑"

这个框架为新兴的 Agent 研究提供了一个共同语言，有助于区分"Agent 在优化什么"这一关键问题。

### 1. GPT-5.6 程序化工具调用与多智能体编排
