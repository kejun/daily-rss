## 📊 论文精选

### 论文 1：VRRL — 视觉 Grounding 的自我反思强化学习框架
**arXiv:2607.02490** | [PDF](https://arxiv.org/pdf/2607.02490)

- **问题：** 大型视觉语言模型（LVLM）在生成思维链（CoT）时，经常无法在反思过程中正确关注视觉输入，限制了其在分布外场景中的纠错能力。
- **方法：** VRRL 框架包含两个核心组件：（1）随机遮蔽轨迹前缀，强调从错误的中间预测中恢复；（2）经验回放缓冲区的缓冲 rollout，暴露模型于多样化失败状态。
- **结果：** 在表格/图表视觉 grounding 任务和空间导航基准上，分布外准确率显著优于标准 RL 和反思微调基线。
- **意义：** 为多模态模型的可靠自我反思提供了新训练范式，对构建可信赖的视觉 AI 系统有重要价值。

### 论文 2：DramaSR-LRM — 推理 LLM 在长剧说话人识别中的应用
**arXiv:2607.02504** | ICML 2026 接受 | [PDF](https://arxiv.org/pdf/2607.02504)

- **贡献：** 引入 DramaSR-532K 大规模基准（53.2 万标注对话行、900+ 角色）和 DramaSR-LRM 方法。
- **方法：** 基于大型推理模型（LRM），通过多模态工具使用自主聚合听觉、语言和视觉上下文证据。
- **结果：** 显著优于现有基线，尤其在声学生物特征不可靠的短话语场景中表现突出。
- **意义：** 展示了推理 LLM 在复杂视频理解任务中的潜力，为长内容理解提供了新范式。

### 论文 3：Object Aligner — JSON Schema 相似度评分与 LLM Prompt 优化
**arXiv:2607.01972** | [PDF](https://arxiv.org/pdf/2607.01972)

- **问题：** LLM 生成结构化 JSON 输出时，缺乏确定性、高效、结构感知的相似度评分方法。
- **方法：** Object Aligner 通过递归对齐 JSON 树（无序集合用匈牙利算法、有序序列用序列对齐）并提供部分得分。引入参照对齐（referential alignment）处理图结构数据，用 Weisfeiler-Leman 颜色细化近似图同构。
- **结果：** 作为 GEPA prompt 优化器的奖励函数，在所有数据集上都有提升或至少持平。
- **意义：** 为 LLM 结构化输出的自动化评估和优化提供了开源工具，对工具调用、Agent 规划和知识图谱构建有直接应用价值。
