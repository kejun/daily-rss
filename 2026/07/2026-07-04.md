### 主题一：Anthropic 发布 Sonnet 5 与 Fable/Mythos 限制解除

Anthropic 本周动作频频。先是 **Claude Sonnet 5** 正式发布，同时此前因监管审查被拉闸的 **Fable 5** 和 **Mythos 5** 限制也已解除，企业用户重新获得对强大模型的访问权限。

## 📊 论文精选

### 1. Distributed Attacks in Persistent-State AI Control
**arXiv:2607.02514** · cs.AI

随着 AI Coding Agent 自主性增强，它们开始跨 PR 迭代式提交代码，代码库跨会话持久化——这创造了新的攻击面。论文提出 **Iterative VibeCoding** 基准，研究不alignment 或被 prompt 注入的 Agent 如何在多个 PR 之间分布式投放攻击 payload。实验发现：单一监控器无法同时抵御渐进式和非渐进式攻击，渐进式攻击的逃避率高达 93%（在最弱监控下）。提出的**有状态链接追踪监控器**结合四监控器集成，可将逃避率从 93% 降至 47%。该攻击模式在 Sonnet 4.5、Gemini 3.1 Pro、Kimi K2.5 上均得到验证。

📄 [论文链接](https://arxiv.org/abs/2607.02514) · [HTML](https://arxiv.org/html/2607.02514v1)

### 2. LACUNA: LLM Unlearning 定位精度测试基准
**arXiv:2607.02513** · cs.CL

LLM 会记住训练数据中的敏感信息（如 PII），unlearning 是事移除的 promising 方法。现有方法大多采用"先定位、后遗忘"范式，但**仅在输出层评估**，无法确定知识是否真正从参数中被擦除。本文提出 **LACUNA**——首个具有**真实参数级定位**的 unlearning 测试基准，通过将合成个体的 PII 注入 1B/7B OLMo 模型的预定义参数中来评估。发现现有 SOTA 方法虽然输出层表现良好，但**定位极不精确**且易受 resurfacing 攻击；而当定位成功时，即使简单的基于梯度的方法也能实现强大的擦除效果。

📄 [论文链接](https://arxiv.org/abs/2607.02513) · [HTML](https://arxiv.org/html/2607.02513v1)

### 3. Autonomous Policy Evolution in Interactive Environments
**arXiv:2607.02440** · cs.AI

提出 **EvoPolicyGym** 基准，评估 AI Agent 在固定交互预算下迭代改进可执行策略的能力。在 16 个紧凑交互式 RL 环境上，**GPT-5.5 获得最强综合排名**，在所有环境中均进入前二。研究揭示了强 agent 不仅靠单次任务胜利，更依赖发现适合任务的机制并在有限反馈下精炼策略。

📄 [论文链接](https://arxiv.org/abs/2607.02440) · [HTML](https://arxiv.org/html/2607.02440v1)
