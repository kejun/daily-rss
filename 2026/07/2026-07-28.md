## 📰 行业深度

### 1. 「回归税」：为什么技能既帮助又伤害 LLM Agent

**来源：** [arXiv:2607.22520](https://arxiv.org/abs/2607.22520)

这篇论文对 LLM Agent 的「技能系统」进行了近 6,000 次实验的量化分析，揭示了一个被忽视的问题：**技能不仅带来增益，还会导致「回归」**——即原本能完成的任务在添加技能后反而失败。研究发现，表现最好的技能之所以胜出，主要不是因为它们带来了更多增益，而是因为它们**导致了更少的回归**。

三种回归模式被识别：(i) 技能描述渗透——技能仅存在于上下文中就会改变 Agent 行为；(ii) 接地位移——技能的预设流程覆盖了 Agent 对输入的解读；(iii) 验证位移——流程抑制了 Agent 原本会执行的输出检查。这对所有构建 Agent 系统的开发者都是重要警示。

### 2. AI Gateway：演化架构的新控制平面

**来源：** [InfoQ](https://www.infoq.com/articles/evolutionary-architecture-pattern/)

传统 API Gateway 假设服务是确定性的、schema 是简单的——这些假设在 agentic AI 时代全部失效。本文提出 **AI Gateway** 作为演化架构的「接缝」，在单一控制平面中集中管理：护栏（guardrails）、模型路由、Agent 身份、操作策略和语义审计。文章详细讨论了零信任安全模型在 AI Agent 场景下的适配，以及如何在保持核心平台稳定的同时防止高成本事故。

### 3. 开源模型的蒸馏之争与地缘政治

## 📊 论文精选

### 1. Skill Self-Play: 通过共演化技能推进 LLM 能力前沿

**论文：** [arXiv:2607.22529](https://arxiv.org/abs/2607.22529) | cs.CL

提出 **Skill-SP** 共演化框架，包含提议者（proposer）、求解者（solver）和动态技能控制器三个组件。通过强化学习循环，提议者基于动态采样的技能生成挑战性任务，求解者探索候选解以推动能力边界。核心洞察：Agent 技能是调和「任务多样性」与「验证可靠性」之间矛盾的最佳中间地带——每个技能确保特定场景的深度可验证执行，而跨技能的动态路由保持开放的任务多样性。

### 2. TRACE-Router: 面向 Agentic AI 的任务级自适应路由

**论文：** [arXiv:2607.22465](https://arxiv.org/abs/2607.22465) | cs.AI + cs.LG + cs.MA

现有 LLM 路由器对每次调用独立决策，但 agentic 应用是长周期工作流，质量由延迟的任务级结果决定。TRACE-Router 在任务准入时用上下文赌博机（contextual bandit）一次性分配模型，后续所有调用固定到该后端，并用任务终端奖励更新策略。在 tau2-Bench 上比延迟匹配的插值方法高 7-8 个精度点，在 Terminal-Bench 上比最强单模型基线高 7.1 个精度点且延迟降低 36%。

### 3. GraphEval: 用图结构评估 LLM 幻觉

**来源：** [KDnuggets](https://www.kdnuggets.com/language-model-hallucination-evaluation-with-grapheval)

将 GraphEval 的关键原则和方法论阶段转化为模拟实践场景，通过图结构化的知识表示来更精确地检测和量化 LLM 幻觉。相比传统的字符串匹配或语义相似度方法，图结构能更好地捕捉实体间关系的正确性。
