### 1. Grok 4.5 卷入政治偏见风暴，马斯克承诺开源系统提示词

### 2. Grok 4.5 登顶 CursorBench，但「训练污染」质疑随之而来

## 📊 论文精选

### 1. Cura 1T: Specialized Model for Agentic Healthcare
**arXiv:2607.15314** · cs.AI
医疗场景同时要求高风险沟通、专家级推理与工作流执行，但能「一肩挑」的专用 LLM 仍然稀缺。Cura 1T 提出一个面向**智能体医疗（agentic healthcare）**的专用模型，试图在单一模型内覆盖问诊对话、临床推理与流程编排。在医疗 AI 从「问答」走向「执行」的当下，这类专用智能体模型代表了垂直落地的重要方向。[论文链接](https://arxiv.org/abs/2607.15314)

### 2. VarRate: Training-Free Variable-Rate KV Cache Compression for Long-Context LLMs
**arXiv:2607.15498** · cs.CL
KV Cache 是长上下文推理的主要内存瓶颈。VarRate 提出一种**免训练、可变速率的 KV Cache 压缩**方法，融合两大主流免训练压缩家族的优点，在不重训模型的前提下显著降低长上下文推理的显存占用。对动辄百万 Token 上下文的今天，这类「即插即用」的推理优化极具工程价值。[论文链接](https://arxiv.org/abs/2607.15498)

### 3. SkillCorpus: Consolidating and Evaluating the Open Skill Ecosystem for Real-World LLM Agents
**arXiv:2607.15557** · cs.CL
「Agent Skills」（以 SKILL.md 打包可复用流程知识）正成为扩展智能体能力的流行机制，但生态碎片化、质量参差。SkillCorpus 首次**系统整合并评估开放的 Skill 生态**，为真实世界 LLM 智能体提供可复用的技能语料与评测基准。这与本周 GitHub 上 harness/agent 生态的火爆形成了学术呼应。[论文链接](https://arxiv.org/abs/2607.15557)

## 💡 编者观察

把今天这一整盘新闻摊开来看，一条主线异常清晰：**AI 竞争的重心，正在从「模型本身」向「模型之外」快速迁移。**
