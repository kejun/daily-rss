## 📊 论文精选

### 1. WorldEvolver：自进化世界模型用于 LLM Agent 规划

**arXiv:2606.30639** — 提出 WorldEvolver 框架，通过 episodic memory（基于检索的模拟）、semantic memory（从预测-观察不匹配中提取启发规则）和 selective foresight（过滤低置信度预测）三个模块，在部署时修订上下文同时保持下游 Agent 和模型参数冻结。在 ALFWorld 和 ScienceWorld 上验证，在三个 backbones 上实现最高预测准确率。

**亮点**：测试时记忆修订同时提升了预测保真度和规划性能，为长视野 Agent 提供了一条无需重新训练即可增强 foresight 的路径。

📎 [论文链接](https://arxiv.org/abs/2606.30639)

### 2. Agents-A1：扩展 Horizon 而非参数 —— 35B Agent 达到万亿参数性能

**arXiv:2606.30616** — 介绍 Agents-A1，一个 35B MoE Agentic 模型，通过 scaling agent horizon 达到万亿参数级别的性能。核心创新：构建长视野知识-行动基础设施，平均 45K token 轨迹，采用三阶段训练（全领域 SFT → 领域级教师模型 → 多教师域路由在途蒸馏）。在 SEAL-0（56.4）、IFBench（80.6）、FrontierScience-Olympiad（79.0）等长视野 Agent 基准上领先 Kimi-K2.6 和 DeepSeek-V4-pro 等万亿参数模型。

**亮点**：证明了小模型可以通过 scaling 交互深度（而非模型大小）来追赶大模型，为社区提供了实用的小模型扩展路径。

📎 [论文链接](https://arxiv.org/abs/2606.30616)

### 3. FlashMorph：高效 Transformer 到混合注意力模型转换

**arXiv:2606.30562** — 提出 FlashMorph，一种高效、可扩展的混合层选择方法。将混合层选择公式化为预算约束的子集优化问题，通过冻结所有模型权重并在合成长上下文检索数据上联合优化层门控，学习到的门控被离散化以实例化混合架构。

**亮点**：相比现有的启发式层选择方法（固定模式或逐层评分），FlashMorph 发现了更有效的混合配置，同时大幅降低层选择成本。
