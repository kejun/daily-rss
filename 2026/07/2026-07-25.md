### 1. Anthropic 发布 Claude Opus 5：不是能力跃迁，而是"效率革命"

沉寂两个月后，Anthropic 在周五推出了 Opus 系列新旗舰 **Claude Opus 5**，一举登上 HN 榜首（1078 分 / 574 评论）。它的定位很微妙——比 Fable 5 小，却更便宜、限制更少，在多数场景下可能反而更值得选。

- **Opus 5 以半价逼近 Fable 5 的智能**：定价维持不变（输入 $5/百万 token、输出 $25/百万 token），Anthropic 称其智能"接近 Fable 5 的一半价格"，现已成为 Claude Max 的默认模型、Claude Pro 上的最强模型，并在多项基准上反超 Fable 5。
  🔗 [Anthropic](https://www.anthropic.com/news/claude-opus-5) · [MarkTechPost](https://www.marktechpost.com/2026/07/24/meet-the-new-claude-opus-5-frontier-class-agentic-coding-and-computer-use-at-unchanged-opus-pricing/)
- **三个 API 层的关键变化**：①思考（thinking）默认开启，由 effort 参数控制深度；②破坏性变更——`thinking: disabled` 搭配 `xhigh`/`max` effort 会返回 400 错误；③官方要求开发者**删掉自己的"验证提示词"**，因为模型已会自我校验，再写"请最后验证一遍"反而会过度验证。模型 ID 为 `claude-opus-5`，上下文 1M token，同步 API 最大输出 128k（Batches API 可达 300k），最小可缓存 prompt 从 1024 降到 512 token。
  🔗 [MarkTechPost](https://www.marktechpost.com/2026/07/24/meet-the-new-claude-opus-5-frontier-class-agentic-coding-and-computer-use-at-unchanged-opus-pricing/)
- **更轻的安全护栏 + "自动降级"新功能**：Opus 5 不受困扰 Fable 的 30 天数据保留政策约束，安全分类器触发频率比 Fable 5 低约 85%。同时上线 beta 功能 **Automatic Fallbacks**——当 prompt 触发安全分类器时，自动把请求路由到较弱模型，让 API 用户拿到可用响应而非报错。
  🔗 [TechCrunch](https://techcrunch.com/2026/07/24/anthropic-launches-opus-5/)
- **Ars Technica 泼冷水：这是 token 效率，不是能力跃迁**：评论指出 Opus 5 并非 Opus 4.5 那种 agentic coding 的突破性飞跃，"模型进步飞快，但更便宜的选项往往已经够用"——一语道破当下模型竞争的重心正从"最强"转向"最划算"。
  🔗 [Ars Technica](https://arstechnica.com/ai/2026/07/anthropics-opus-5-is-about-token-efficiency-not-a-capability-leap/)

### 2. Black Forest Labs 放出 FLUX 3：从生成视频一路开进奥迪工厂

以图像模型闻名的德国实验室 Black Forest Labs（BFL）周五开放了 **FLUX 3** 的早期访问，这是一个"视觉智能（visual intelligence）"统一模型，更惊人的是它的机器人变体 **FLUX-mimic** 已经上了奥迪的生产线。

- **FLUX 3：一个模型生成视频、图像与同步音频**：可产出 20 秒带原生音频的短片，支持多语言对话、排版文字、风格与角色一致性，接受文本/图像/视频输入；BFL 的测试显示其输出比 Runway、Kling、Grok Imagine 更受偏好。完整路线图还包括开放权重的 FLUX 3 Dev，尺寸可塞进工厂硬件。
  🔗 [BFL: FLUX 3](https://bfl.ai/blog/flux-3)（HN 543 分 / 128 评论）
- **FLUX-mimic：用视频模型驯服机器人**：与苏黎世的 mimic robotics 合作，把"模拟世界如何运动"的视觉能力用于训练与操控物理机器。关键突破是**数据效率**——学一个新的工厂任务只需约半小时演示数据，而传统方法通常要 30+ 小时。
  🔗 [BFL: FLUX 3 Mimic](https://bfl.ai/blog/flux-3-mimic)（HN 297 分 / 47 评论）
- **The Rundown 的评价**：BFL 一向节奏偏慢，但这次统一系统像是"厚积薄发"——更长、音画同步、连贯的视频让人想起 Sora 的高光时刻（褒义）；而 mimic 意味着视觉模型正持续渗入物理世界，成为机器人的关键齿轮。
  🔗 [The Rundown AI](https://www.therundown.ai/p/black-forest-labs-teaches-video-ai-to-run-robots)

### ① Is MoE Routing a Huffman Code? 发现思维链中的"频率-多样性定律"

**作者**：Ching-Chieh Tsao, Zhuoyi Lin, Wenya Wang（arXiv:2607.20427，cs.CL / cs.AI / cs.IT）

MoE（混合专家）架构革新了模型扩展，但其路由逻辑一直是个黑箱。这篇论文给出了一个出人意料的统一解释：**MoE 路由本质上是霍夫曼编码（Huffman Coding）的一种表现**。作者提出"频率-多样性定律（Frequency-Diversity Law）"——Phi-3.5-MoE、Gemma-4-27B-A4B 等前沿模型会自发地充当"信息论引擎"：为常见 token 分配稀疏的专家资源，而在思维链轨迹中那些罕见、复杂的任务上召集高多样性的专家委员会。但作者也在 Qwen3.5-35B-A3B 中发现了一个"冗余陷阱"：当有效稀疏度足够低时，负载均衡会无意中强加功能冗余，掩盖底层的霍夫曼效率信号。为此他们提出"子集差异剪枝（Subset Difference Pruning）"，外科手术式地剔除功能重复——剪枝不但不损害推理，反而释放出潜在的霍夫曼效率。论文主张，下一代 MoE 应从"强制负载均衡"走向"最小描述长度（MDL）最优"，把路由从启发式变成有原则的压缩引擎。
🔗 [arXiv:2607.20427](https://arxiv.org/abs/2607.20427)

### ② EAACD：用"专家感知对比解码"缓解 MoE 的幻觉

**作者**：Xinyue Fang 等（arXiv:2607.20426，cs.CL / cs.AI）

现有的幻觉缓解方法（提示工程、模型优化）要么难以改变模型内部知识，要么跨领域泛化差。对比解码利用 LLM 的逐层差异来缓解幻觉，但既往研究只关注 Transformer 模型（如 GPT），忽略了 MoE。本文通过实证发现：在带共享专家的 MoE 中并不存在类似 Transformer 的逐层差异；然而在不同 MoE 的高层之间，事实性输出与非事实性输出确实呈现出不同的专家激活模式。基于此，作者提出 **EAACD（专家感知自适应对比解码）**：把高层专家按置信度与一致性分成一个高可靠组与若干低可靠组，用高可靠组的预测与每个低可靠组的预测做对比来校准原始输出，并通过注意力与掩码放大低可靠专家的幻觉以提供更强的负向参照。在四个数据集上，EAACD 全面超越所有基线。
🔗 [arXiv:2607.20426](https://arxiv.org/abs/2607.20426)

### ③ What is Good? 从 LLM 推理轨迹中提取并检验"文学质量的隐含理论"

**作者**：Birger Moell（arXiv:2607.20425，cs.CL）

什么让写作成为"好"写作？这篇论文用两项研究考察具备推理能力的 LLM 如何评价文学质量。研究一构建了一个涵盖六个质量层级（从经典文学到匿名论坛帖）的 30 篇真实文本基准，从模型推理轨迹中提取其"隐含质量理论"——在五次 DeepSeek 重复实验中，模型平均层级分类准确率达 79.3%，其表述出的理论一致地"看重意图性而非正确性"，优先考虑技艺、深度与独特声音。研究二通过对五篇经典散文做系统性降级（词汇简化、节奏扁平化、意象移除、声音泛化、结构简化等六种操作）来探测这一理论：词汇简化造成的质量损失最小（0.41 分），远低于结构（2.78）或声音（2.34）的损失；组合降级是毁灭性的（-5.64）但呈次可加性。结论是：LLM 对写作质量的判断是整体的、作者特定的，且对结构特征比词汇特征更敏感——这对自动写作反馈与计算美学都有启示。
🔗 [arXiv:2607.20425](https://arxiv.org/abs/2607.20425)
