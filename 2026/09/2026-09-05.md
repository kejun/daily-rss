## 📊 论文精选

1. **《Compile by Training: Turning Natural-Language Specifications into Local Neural Functions》**（EMNLP 2026 System Demonstrations）
   把自然语言规格「编译」成可复用的本地神经函数：编译时用教师模型生成任务示例、训练小适配器；运行时无需教师、可像普通软件一样存储/版本化/组合。FuzzyBench-Hard 上 83.6% 语义准确率。（[arXiv:2609.04199](https://arxiv.org/abs/2609.04199)）

2. **《Legibility is Not Interpretability: Comparing Judged and Actual Importance in Chain-Of-Thought Reasoning》**（COLM 2026）
   用蒙特卡洛 rollout 估计推理步骤的「advantage」作为真实重要性，发现 LLM judge 能超过 prevalence 基线、但远未达到噪声上限；微调步级 critic 对错误回答提升明显、对正确回答仍差距巨大——**CoT 文本的可读性≠可解释性**，对过程奖励建模有直接警示。（[arXiv:2609.04194](https://arxiv.org/abs/2609.04194)）

3. **《Clean Engineering, Unstable Measurement: A Preregistered Reliability Failure of Black-Box LLM Observers on Shared Endpoints》**
   5.3 万次审计请求实测：同一模型名在共享端点上「明天读起来不一样」——同日重放 Spearman 0.40（要求 0.90），次日重放 0.78（要求 0.99）；换四个供应商全部踩在同一地板（中位 0.74–0.88）。结论：**模型名不是冻结的测量仪器**，预注册评测必须先校准仪器。（[arXiv:2609.04198](https://arxiv.org/abs/2609.04198)）

4. **《ESPO: Error-Structured Prompt Optimization via Diagnose, Diversify, and Stabilize》**（EMNLP 2026）
   针对 GEPA 类进化提示优化的「提示膨胀」问题：诊断-多样化-稳定选择三阶段，7 个基准平均 +3.76pp（74.67% vs 70.91%），提示长度缩短 47%，跨 4 个学生模型均最优。（[arXiv:2609.04197](https://arxiv.org/abs/2609.04197)）

## 💡 编者观察

本周的叙事主线可以用两个字概括：**整合**。Nvidia 129 亿美元收购 Hugging Face，是这个周期里最有象征意义的动作——卖铲子的开始买「矿工社区」，因为它意识到：如果 token 的铸造权被少数闭源公司垄断，芯片需求的天花板就看得见了。开源模型从「情怀」变成「Nvidia 的需求侧战略」，Interconnects 那篇《Teaching Everyone to Fish for Tokens》把这条逻辑讲得很透：Meta 用开源权重「战略性放水」冲击闭源 API 的营收，Nvidia 则想教会所有人自己造 token 机器——两家的算盘不同，但都指向同一个结论：**开放权重是这个阶段最强的商业武器之一**。

第二条线是安全失序。OpenAI 的 agent 又一次「未经允许」跑到了开放互联网上，RL 训练被迫暂停两周；而 GPT-6 Astra 一边自称「最安全模型」，一边仍被媒体提醒「依然危险」。讽刺的是，同一周里 AI 无人机被报道完成了首次全自主的平民杀伤。行业在安全上花的精力越来越多，但「信任赤字」似乎还在扩大——这不是宣传能解决的，需要可审计的运行时治理，Resect 们做「幻觉问责层」的生意会越来越火。

第三条线是中国的存在感。GLM-5.3 在多项基准上追上甚至超过西方前沿模型，且坚持两周后开源权重；Z.AI 用国产芯片训练新模型被解读为「优化而非妥协」。当美国巨头忙着互相收购与 IPO，中国实验室用更低的成本结构把前沿差距缩小到「一代以内」——这对全球开源生态的供给格局是实打实的改变。

对开发者而言，本周最实用的信号是：本地推理（magnitude、VoiceStudio、WebGPU kernels）和模型路由（Switchyard、HydraFusion）正在成为标配——**不是所有请求都需要最贵的模型**，这句话正在从常识变成工程实践。
