## 📊 论文精选

1. **《Show-Harness: Just a VLM Agent Can Play Robots》**（arXiv:2609.10522）
   让 VLM 通过「语义动作单元」接口直接「玩」机器人：无需额外训练即可解锁闭源前沿 VLM 的零样本机器人控制，小规模开源 VLM 只需几 GPU 小时微调即可低成本部署；配套 GUMI 界面还支持用 GUI 演示收集训练数据。实验表明 Show-Harness 在多个任务/本体/环境中超越代表性 agentic 与 VLA 范式——「对的接口就能撬动具身能力」。[原文](https://arxiv.org/abs/2609.10522)

2. **《JarvisGUI: Towards Cross-Device GUI Agents with Dynamic Task Composition》**（arXiv:2609.10451，EMNLP 2026 主会录用）
   首个跨设备 GUI agent 动态基准：把任务建模为输入-输出变换，自动组合跨 Android/Windows/Ubuntu 的多步骤工作流。结果揭示 SOTA 开源 GUI agent 在状态迁移感知、跨平台上下文推理与长程依赖管理上的严重短板——现有单设备基准严重高估了 agent 的真实可用性。[原文](https://arxiv.org/abs/2609.10451)

3. **《ConvMem: Convolutional Memory for Long-Context Reasoning》**（arXiv:2609.10441）
   受 CNN 启发的免训练长上下文推理框架：把 LLM 当作「卷积核」，将长文本分段做层次化摘要，把推理路径从线性链缩短为对数树；可配置步长+跳跃连接保证证据捕获，多核卷积把复杂查询拆成解耦语义通道。在 RULER-HotpotQA 与 RULER-2WikiMultiHopQA 上超越所有免训练基线，且规避了 RL 训练方法在 OOD 任务上的过拟合风险。[原文](https://arxiv.org/abs/2609.10441)

4. **《Building Multilingual Bridges: Data Mixing as the Pillar of Generalization for In-Language Reasoning》**（arXiv:2609.10445）
   打造 3.35B 的 Tiny Aya L2-Thinker，仅靠数据配比与调度，就让模型在 60 种语言、6 个基准上的「L2 推理率」超过 93%——推理是一种与语言无关的行为，可通过数据混合跨语系迁移，无需为每种语言准备推理监督数据。权重与数据已开源。[原文](https://arxiv.org/abs/2609.10445)

## 💡 编者观察

今天的日报有一条清晰的暗线：**AI 产业正在从「发布模型」切换进「消化模型」阶段**。

先是供给侧。GPT-6 Astra 火到让 OpenAI 暂停 Pro 订阅——这是过去两年我们见过的所有「产能不足」里最特别的一次：不是缺卡，而是缺「能跑得动旗舰模型的卡」。当最强模型反而成为瓶颈，说明需求曲线已经超越了供给曲线，这比任何 benchmark 分数都更能说明模型的实际价值。与此同时，Cognition 携 SWE-2 和 $48B 估值杀到，把「AI 程序员」的叙事从演示推向基准分数（Terminal-Bench 92.8），编程 agent 的竞争从「谁能写代码」变成「谁的能量产」。

其次是需求侧。Meta Muse 冲到美国 App Store 第二、AI agent 开始批量提交公共福利申请、Pocket FM 用 AI 把内容成本压到 1/80——个人代理、政务自动化、内容工厂三个方向同时出现「真实付费用户」。当 agent 开始替人办事、替人申请、替人生产，我们谈论的就不再是技术 demo，而是社会基础设施的换轨。这也是 Anthropic 连发蒸馏指控与威胁情报月报的原因——滥用与治理永远同步进化。

最后是反思侧。今天 HN 和 Newsletter 里最动人的不是任何模型新闻，而是两篇「人」的文章：Celine Nguyen 说模型读过 48 万本书却写不出打动人的短篇；Jason Gorman 说 AI 编程是放大器不是修复器。当整个行业都在卷「更强」，这些声音提醒我们：**品味、判断力、亲手写下的代码，依然是无法外包的核心资产**。技术的正确姿势，或许真的是 Jim Nielsen 说的那句——「别让任何人夺走你那盒子线缆」。

—— 小R · 2026-09-11
