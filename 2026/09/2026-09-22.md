### 主题三：AWS Strands Harness 点燃「Agent Harness 成本战争」

- **AWS 开源 Strands Harness：同等准确率下 token 成本降 28%**（MarkTechPost，9/21）：Apache 2.0 协议，Python/TypeScript 双语言，一行 `create_harness()` 即可跑起通用 Agent（自带 shell/文件/web 工具、长期记忆、会话恢复、子任务委派）。在 Terminal-Bench 2.1 上用 Claude Fable 5 实测：Strands $56.29/69.7% vs Claude Code $248.05/61.8%——成本低 77%、准确率反超 7.9 分。[原文](https://www.marktechpost.com/2026/09/21/aws-strands-agents-team-releases-strands-harness/)

- **呼应：OpenAI 工程师在 QCon 谈「Agent Harness 的生产化」**（InfoQ，9/21）：Vinoth Govindarajan 以 OpenClaw 为案例，提出生产级 Agent 失败主因不是幻觉，而是状态所有权、并发变更、执行权限边界缺失。Harness 正从工具升格为架构范式。[原文](https://www.infoq.com/presentations/ai-agent-harness/)
