## 📊 论文精选（arXiv 最新）

### 1. Learning to Stop without Learning to Stop: Self-Supervised Confidence Training Improves Reasoning Efficiency
**arXiv:2609.31619**（cs.AI/cs.CL，NVIDIA 系作者团队）
推理模型动辄生成超长思维链，推理成本高企。现有方法要么在推理时做 early-stopping，要么用长度惩罚的 RL 显式压缩推理。本文另辟蹊径：用**自监督置信度训练**——仅用 600 道训练题，让模型在自己推理轨迹的中间点预测「对答案的置信度」，损失函数中**完全没有**长度/效率/停止目标。结果：在 Gemma、Qwen、Nemotron、GPT-OSS 上，同等准确率下生成 token 减少最多 25%，且推理时不需要任何置信度机制。结论很哲学：**高效推理可以是学会元认知信号的副产品，而非直接优化的目标**。
→ [论文链接](https://arxiv.org/abs/2609.31619)

### 2. User Model Extraction via Belief Self-Distillation
**arXiv:2609.31603**（cs.CL）
LLM 会隐式推断用户属性并调整行为，但这些「信念」难以检视和干预。本文提出 **BSD（Belief Self-Distillation）**：冻结的 LLM 当自己的老师，从自然对话中蒸馏出紧凑的用户表征，既可读出也可写回。两个惊人发现：① 模型是否拒绝，不仅取决于请求本身，还取决于它**推断的用户意图**——固定请求、改写用户信念就能翻转拒绝行为；② 独立训练的不同 LLM 收敛到**共享的用户表征几何结构**。对可解释性和对齐安全都有直接意义。
→ [论文链接](https://arxiv.org/abs/2609.31603)

### 3. Statistical attribute alignment for black-box generative AI via output post-processing
**arXiv:2609.31607**（cs.AI）
黑盒场景下（只能反复查询生成模型），如何让输出的属性分布（如性别/种族/年龄）对齐用户指定的目标分布？本文给出查询次数最优的后处理算法，并证明 m→∞ 时的最优性。文生图和地理画像生成实验显示，后处理与提示词干预互补——公平性不必重训模型也能做。
