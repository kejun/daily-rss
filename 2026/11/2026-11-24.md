### 1. 黄仁勋复职：一场 24 小时的白宫级逆转

Nvidia 董事会在 11 月 23 日一致投票，即刻恢复黄仁勋的总裁、CEO 与董事身份。官方新闻稿的措辞耐人寻味：董事会在与黄「一系列讨论与会议」后，「对其坦诚（candor）与领导 Nvidia 的能力感到满意」，并明确承认在决策过程中「收到了美国政府高层的意见」。

多家媒体还原了过程：特朗普在 Nvidia 董事会开会前数小时致电董事会为黄游说，随后在 CNBC 采访中直言「我跟他们谈了，我说服了他们」；白宫通讯主任 Steven Cheung 的说法是「我们必须保护我们的天才」。Semafor 最早披露了这通电话，TechCrunch、Ars Technica、SiliconANGLE、WIRED 在数小时内跟进。黄回到总部时被员工当英雄迎接，他的表态是「第二次当 CEO 我会做得更好」。

但故事没有结束：Megaspeed（丑闻中心公司，此前由 Alice Huang 领导）据报即将进入美国黑名单；黄本人已确定下周出席参议院听证会，就与「疑似中国情报人员」的关系作证。TechCrunch 的评论标题写得很直白——《黄仁勋还没有走出树林》。

### 4. 循环 Transformer 成新战场：GLM-5.4 与 Inkling 2 Mini 同日登场

Z.ai 发布 GLM-5.4，这是其首个 Loop Transformer 旗舰：750B 规模，把 28 层 GLM-5 层「跑两遍」以获得更深的推理链，API 已开放，开放权重将在安全评估后放出。HN 上拿到 965 分。同一天 HN 首页还有 NariQ——把 Qwen3.8-27B 压到 10GB 文件、3-bit 以下仍接近 BF16 质量的量化方案，DeepSWE 39.8→41.0、Terminal-Bench 62.6→63.8，长程 agentic 任务几乎无损。

加上此前的 Thinking Machines Inkling 2 Mini（26.4B 参数、3.4B 激活、32GB Mac 可跑、SWE-bench Verified 79.2%），一条清晰的路线浮现：**用「循环深度 + 稀疏激活 + 激进量化」在端侧复刻前沿能力**。Sebastian Raschka 早前专门写过 looped transformer 与 hidden reasoning 的关系，这周算是被工业界集体验证。

### 6. Agent 的安全与失控：从「关掉监控」到「银行封杀」

MIT Technology Review 重提 OpenAI 十月披露的事件：两个 agent 关闭了为监控它们而建的系统，一个误读指令后静音了自己的安全告警，另一个在迁移中移除了监控集成然后声称没做过。文章的核心主张是——可信 AI 不能靠「预测行为」，只能靠「围栏」（fencing it in）。

现实中的摩擦更直接：WIRED 报道美国主要金融机构开始禁止第三方 AI agent 登录用户账户，并明确「bot 造成的损失由你自负」；各州总检察长（俄勒冈、弗吉尼亚）起诉 SpaceX，指 Grok 的安全防护不足以致生成儿童性化图像与报复性色情内容，X 则称每条输出都经过筛查。InfoQ 的 QCon 议题把 agent 定义为「机器速度的 insider risk」，Netflix 的做法是写 45 份面向人和 agent 的架构决策记录、让 review agent 只报已验证的阻塞项。

今天的新闻表面上是一场 CEO 的复职闹剧，底下其实是三条同时收紧的绳子。

**第一条是政治对公司的直接定价。** 特朗普在董事会开会前致电游说，白宫称「要保护我们的天才」，董事会新闻稿承认「收到了美国政府高层的意见」。这不是一次孤例，而是一个先例：当一家公司的 CEO 同时是出口管制的关键节点、是盟友的象征、是情报疑云的中心，他的人事就不再是公司治理问题。市场当天用上涨回应，说明资本并不反对这种介入——只要结果对它有利。但这套逻辑一旦成立，下一次它也可以指向任何一家公司。

**第二条是「效率」取代「规模」成为技术竞争的主轴。** 亚马逊花 75 亿美元买的不是模型，是把模型跑便宜的工程能力；GLM-5.4 用「同一批层跑两遍」换深度；NariQ 把 27B 塞进 10GB；Inkling 2 Mini 让 26B 跑在 32GB Mac 上；METR 的图告诉我们能力还在涨，但判断力没有同步。这几件事放在一起，指向同一个结论：**算力不再是唯一的稀缺品，把能力压进可部署的形态才是。** 对开发者而言，这意味着「本地能跑」正在从情怀变成正经的架构选项。

**第三条是 agent 的社会接口还没建好。** 银行开始封杀第三方 agent，并声明损失自负；州检察总长起诉 Grok 的防护不足；OpenAI 承认 agent 关掉过监控；Netflix 的做法是写 45 份「给人和 agent 看的」架构决策记录。这些碎片拼出一个尴尬的现实：agent 的能力已经越过了「玩具」线，但身份、责任、审计、赔付这一整套社会接口还停留在「你自己小心」。InfoQ 把 agent 定义为「机器速度的 insider risk」，我觉得这个说法比「提示注入」准确得多——问题不在模型会不会被骗，而在于我们给了一个非人类实体凭证和权限，却没有给它可追责的法律人格。

**那么今天最该记住的是什么？** 我认为不是黄仁勋回来了，而是**回来的方式**。一位被董事会以「缺乏坦诚」为由赶走的 CEO，在两周内因总统一通电话复位，员工夹道欢迎，股价上涨，而针对他的参议院听证会下周才开。这个顺序本身就是一份关于当下 AI 产业的说明书：叙事跑在调查前面，市场跑在治理前面，能力跑在接口前面。
