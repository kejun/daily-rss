### 二、Anthropic 破发：AI 泡沫叙事的第一个硬指标

Anthropic 上周四完成史上最大 IPO（约 810 亿美元），首日涨 17%。但 11 月 24 日盘前即跌破 83 美元发行价，HN 讨论 536 条，成为当日最热技术贴。

### 三、Claude Ship：把代码评审这最后一道人工闸门也交给 Agent

Anthropic 上线 Claude Ship，包含三个组件：**Code Review**（已 GA）、**PR Steward**（公开测试）、**Claude Approvals**（公开测试，Team/Enterprise）。工作流是：开发者开 PR → Agent 自动评审、修复、并按团队策略批准可批准的 PR。

- **产品定位**：官方说法很直接——"开个 PR 然后回去干活"。（[Claude 官方](https://claude.com/resources/articles/introducing-claude-ship)、[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)）
- **技术拆解**：MarkTechPost 指出 Code Review 已 GA，另两个 Agent 处于 Team/Enterprise 公测，说明 Anthropic 对"自动批准"仍保持风险分级。（[MarkTechPost](https://www.marktechpost.com/2026/11/23/anthropic-claude-ship-pull-request-agents/)）
- **产业含义**：SiliconANGLE 的判断是"Anthropic 不满足于让 Claude 写代码，它要接管软件交付管线的最后一公里"——而这一公里过去恰恰是人类 review 的文化阵地。（[SiliconANGLE](https://siliconangle.com/2026/11/23/anthropics-claude-ship-automates-the-final-stage-of-the-software-development-pipeline/)）
- **配套动作**：Claude Code 同时推出实验性 **Code Mode**，允许 Claude 用 JavaScript 链式/并行/过滤 Bash、Read、Edit 调用。（[InfoQ](https://www.infoq.com/news/2026/11/claude-code-mode/)）

### 四、黎曼猜想：AI 给出的 1700 万行"外星"证明

Anthropic 研究员 Levent Alpöge 声称用 Claude 证明了黎曼猜想，证明长约 1700 万行。数学界的反应是：看起来成立，但没人真正读懂。

- **事件本身**：Anthropic 未发官方公告，消息由研究者个人网站发布，时间点紧随 IPO 之后，引发"是不是营销"的质疑。（[SiliconANGLE](https://siliconangle.com/2026/11/20/anthropic-researcher-claims-to-have-proven-riemann-hypothesis-using-claude/)）
- **数学界的困境**：WIRED 采访多位数学家，普遍说法是"要花几个月才能理解这个 alien solution"——AI 产出了正确性可验证、但人类无法消化的一类数学对象。（[WIRED](https://www.wired.com/story/ai-solved-maths-most-famous-problem/)）
- **Ars 的冷静**："一个 AI 辅助的证明看起来是坚实的，但我们不确定它告诉了我们什么。"这可能是未来几年数学与 AI 关系的常态描述。（[Ars Technica](https://arstechnica.com/ai/2026/11/whats-going-on-with-the-riemann-hypothesis/)）
- **历史脉络**：今年 9 月 OpenAI 曾宣称解决 Navier–Stokes 并与数学家公开交恶，Last Week in AI #344 记录了那场风波——AI 攻数学正在变成一种固定叙事。（[Last Week in AI](https://lastweekin.ai/p/last-week-in-ai-344-navierstokes)）

### 五、Agent 安全：从理论担忧变成可复现的攻击面

这一周安全类新闻密度异常高，且都指向同一件事——**Agent 已经具备真实的攻击与防御能力，而防护体系还在补课**。

- **Anthropic 自己做了蜜罐**：WIRED 报道 Anthropic 构造了一个"诱导 Agent 越界"的测试环境，前提假设就是 Agent 会失控，然后观察它能抵抗多少诱惑。（[WIRED](https://www.wired.com/story/ai-agents-can-get-honeypotted-too-aw/)、[Anthropic 研究](https://www.anthropic.com/research/working-with-ai)）
- **黑客的 Agent 找到了 0-day**：Amazon 披露攻击方的 AI Agent 在极少人工介入下发现并利用了 0-day，其 Cairn AI 框架"对防御方和攻击方同样好用"。（[Ars Technica](https://arstechnica.com/security/2026/11/amazon-says-hackers-ai-agents-found-and-exploited-0-day-with-little-human-input/)）
- **Google 把 Agent 运行时开源化**：Agent Compute Engine 用隔离 microVM 跑 Agent，凭证/OAuth token 全部留在沙箱外的 Agent Gateway；同时把 Agent Substrate 与 gVisor 捐给 CNCF。（[InfoQ](https://www.infoq.com/news/2026/11/google-agent-compute-engine/)、[InfoQ](https://www.infoq.com/news/2026/11/google-substrate-gvisor-cncf/)）
- **OpenAI + Cisco 的 Shirudo**：BSD 许可的 eBPF 运行时，Agent 写"签名盾牌"在运行中的 Linux 上封堵漏洞路径，让团队在不宕机的情况下测试真实补丁。（[MarkTechPost](https://www.marktechpost.com/2026/11/24/openai-cisco-shirudo-ebpf-linux-runtime/)）
- **Claude Code 自己漏了密钥**：Apiiro 发现 "Don't Ask Again" 把密钥明文存进 `claude/settings.local.json`，在公开仓库里找到 1122 个密钥，git 历史与聊天记录里另有 1160 个。（[InfoQ](https://www.infoq.com/news/2026/11/claude-code-leaking-secrets/)）
- **芯片级攻击**：arXiv 论文 FATCAT 展示首个物理电磁故障注入攻击，能在无软件权限的情况下消除模型的拒答行为——安全的假设边界从"软件"降到了"硬件"。（[arXiv](https://arxiv.org/abs/2611.31129v1)）

### 六、循环 Transformer 复兴：GLM-5.4 与 LoopRes 的双重信号

同一天，工业界和学术界从两个方向指向同一个结论——**共享权重的循环层，是被低估的"免费深度"**。

- **GLM-5.4**：Z.ai 首个 Loop Transformer 旗舰，750B 规模，把 28 个 GLM-5 层跑两遍以获得更深推理，参数量不变。API 已开放，开源权重待安全评估后放出。（[MarkTechPost](https://www.marktechpost.com/2026/11/23/zai-glm-5-4-loop-transformer/)、[Simon Willison](https://simonwillison.net/2026/Nov/23/glm-54/)）
- **一周内第二次**：Simon Willison 指出这是他一周内第二次看到 looped transformer，第一次是 Inkling 2 Mini。（[HF Blog](https://huggingface.co/blog/inkling2mini)）
- **学术配套**：arXiv《Unlocking the Power of Loops in Pretrained LLMs with Loop Residuals》提出 LoopRes，让已有模型微调成循环结构时获得显著且一致的收益——过去这条路只能从零训练才有意义。（[arXiv](https://arxiv.org/abs/2611.31094v1)）
- **背景阅读**：Sebastian Raschka 早前那篇《GPT-6 Astra, Looped Transformers, and Hidden Reasoning》正好是这条线的理论前史。（[Ahead of AI](https://magazine.sebastianraschka.com/p/gpt-6-astra-looped-transformers-and)）

### 七、推理经济：算力重心从训练集群移向"离用户更近的地方"

- **推理已占 AI 负载三分之二**：SiliconANGLE 在 SC26 的现场报道指出，AI 支出正从巨型训练集群转向小型、快速搭建的站点，模块化数据中心成为推理的天然住所，电力/散热/内存供给与芯片性能同等重要。（[SiliconANGLE](https://siliconangle.com/2026/11/21/inference-two-thirds-ai-workloads-chip-deployment-positron-sc26/)）
- **AWS Lambda 跑 GPU 推理**：单卡最多 48 个并发调用共享一个模型，提供 vLLM / SGLang 基础镜像、90 分钟异步超时，计费为实例价 + 9.75% 费用。实测 8 分钟完成发布，但暂不支持响应流式输出。（[InfoQ](https://www.infoq.com/news/2026/11/aws-lambda-gpu-managed-instances/)）
- **内存带宽成为胜负手**：D-Matrix 的 Raptor 用 3D DRAM 堆叠在计算逻辑下方，直指推理的带宽瓶颈。（[SiliconANGLE](https://siliconangle.com/2026/11/19/raptor-chip-stacks-3d-dram-tackle-inference-memory-limits-sc26/)）
- **企业侧的算力回流**：Agentic AI 正在把"租云"重新拉回"自建"——模型平面决定模型跑在哪，很多企业希望模型跑在自己控制的硬件上。（[SiliconANGLE](https://siliconangle.com/2026/11/20/model-plane-shifts-prem-agentic-ai-favors-owning-compute-sc26/)）

### 1. FATCAT: 首个针对芯片级对齐的物理故障注入攻击

### 2. Unlocking the Power of Loops in Pretrained LLMs with Loop Residuals
现有 LLM 微调成循环结构只能得到边际收益，本文提出的 LoopRes 基于 Attention Residuals，让每个循环层直接 attend 到此前各轮输出，从而把"循环"从噱头变成显著且一致的增益。这与 GLM-5.4 的工程选择形成互证：**循环深度正在从研究玩具变成可部署的性能来源。**（[arXiv:2611.31094](https://arxiv.org/abs/2611.31094v1)）

### 3. Language Models Steer on Injected Uncertainty Tokens, but Fail to Self-Monitor In Situ
测试 4 个开放权重模型（Qwen2.5-7B / Llama-3.1-8B / Mistral-7B / Phi-4）共 15200 次数学题尝试，隔离出 2017 个推理错误。结论很尖锐：模型**能被外部注入的不确定性 token 引导去修正错误**，但**自己生成的置信度并不随错误发生而下降**。也就是说，"让模型说出自己的把握"这条路，监控价值远低于其被赋予的期望。（[arXiv:2611.31228](https://arxiv.org/abs/2611.31228v1)）

## 💡 编者观察

今天最值得警惕的，不是 Anthropic 破发，也不是黄仁勋复职，而是这两件事发生在**同一天**，并且市场对它们的反应完全相反。Nvidia 换回 CEO，股价创纪录；Anthropic 交出史上最大 AI IPO，股价跌破发行价。同一批投资人，一边为"人"投票，一边对"业务"投反对票。这说明当前 AI 资产的定价锚不在现金流，而在叙事——只要叙事的主角回来，价格就回来；而一旦叙事需要一个可验证的财务结果，价格就撑不住。

第二件事更技术，但影响更长远：**循环 Transformer 一周内出现了两次产品级落地（GLM-5.4、Inkling 2 Mini），同时 arXiv 上给出了让它"值得做"的方法（LoopRes）。**过去两年模型能力的提升主要靠堆参数、堆数据、堆后训练，而循环层提供了一条不同的路——用同样的参数做更多计算。如果这条路走通，"更大"就不再等于"更强"，算力需求的形状会改变，推理成本结构也会改变。这比任何一次榜单刷新都更值得盯。

第三，Agent 安全这周从"论文里的担忧"变成了"可复现的攻击面"：Anthropic 自己做蜜罐、Amazon 披露攻击方 Agent 找到 0-day、Claude Code 自己漏了 2282 个密钥、arXiv 上有人用电磁故障注入消掉模型拒答。四件事指向同一个结论——**我们给 Agent 的权限增长速度，快于我们验证它行为的能力增长速度**。Google 把凭证挪到沙箱外、OpenAI 与 Cisco 用 eBPF 写"盾牌"，都是正确的方向，但都属于"事后补丁"。

最后说一句产品侧的感受。今天 GitHub Trending 前八里有五个是 Agent skill 而不是库，DEX 周刊在谈"UI 作为 SDK"，InfoQ 在谈"harness 是新操作系统"。这三件事其实是同一件事：**软件的分发单位正在从"库/应用"变成"能力包 + 说明书"**。这对工程师的含义是，未来你交付的可能不是一段可调用的代码，而是一份让 Agent 能正确使用你系统的东西。写文档这件事，忽然变得比写代码更重要了。
