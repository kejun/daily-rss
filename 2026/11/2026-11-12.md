### 2. Fable 5.2 全面铺货：一个模型、两套安全阈值

Anthropic 这次最聪明的地方不是能力，而是**把同一个模型切成两个名字卖**，顺便把"安全等级"变成了产品分层。

- **Fable 5.2 与 Mythos 5.2 核心能力完全相同**，差别只在 Fable 屏蔽部分生物与网络安全用例，Mythos 放宽。链接：https://www.marktechpost.com/2026/11/10/anthropic-claude-fable-5-2-mythos-5-2-release/
- **硬指标**：FrontierCode 2.0 得 49.1%，1M token 上下文，$8/$40 每百万 token。链接：https://siliconangle.com/2026/11/09/anthropic-launches-fable-5-2-and-mythos-5-2-with-science-coding-upgrades/
- **官方口径是 "pacing, not pausing"**：The Rundown 抓住了要害——Anthropic 说的是"我们在控制节奏"，不是"我们在暂停"。链接：https://therundownai.beehiiv.com/p/anthropic-says-pacing-not-pausing-with-fable-5-2
- **一个反直觉的提示词效应**：如果提示词把代码库描述成"别人的"，模型倾向在既有结构上堆叠、甚至复制重复代码；只有明确说"这个代码库是你的"，它才会主动重构去重。链接：https://simonwillison.net/2026/Nov/10/prompting-claude-fable-52/
- **3D 实测**：Willison 让它用 OpenStreetMap 数据做了一个"扬克斯站起来变成机甲、踩过曼哈顿和布鲁克林"的 Three.js 动画，模型还正确推断出他打错的 "átomos" 其实是 "stomps"。链接：https://simonwillison.net/2026/Nov/10/yonkers-rises/
- **办公三件套补齐**：Claude Sheets、Claude Whiteboards、升级版 interactive connectors 同日上线，Claude 直接从聊天框挤进 Excel 和 Miro 的地盘。链接：https://claude.com/resources/articles/more-ways-to-work-with-claude-sheets-whiteboards-and-interactive-connectors

> 观察："所有权"写进提示词就能改变重构行为，意义远超提示技巧——模型内部存在一个**隐式责任模型**。以后给 Agent 派活，第一句话可能不是"做什么"，而是"这是你的代码"。

### 4. AWS 用 Agent 蜂群三周写完一个官方模拟器：29,684 次提交

这是今年最值得反复看的一条工程新闻，因为它把"Agent 写生产代码"从 demo 推到了官方产品线。

- **官方模拟器发布**：可以在本地跑 AWS 各项服务的克隆，不必开付费 API key 就能写集成测试。链接：https://github.com/aws/aws-emulator
- **Rust 编写，前三周 29,684 次提交**：Simon Willison 的原话是"a huge swarm of agents"。链接：https://simonwillison.net/2026/Nov/11/aws-emulator/
- **AWS 自己写了复盘**：Swami Sivasubramanian 在 Werner Vogels 的 allthingsdistributed 博客客座发文讲了它怎么来的（HN 讨论帖里有原始链接）。链接：https://news.ycombinator.com/item?id=50456631
- **HN 480 分、162 条评论**：讨论焦点不是"能不能用"，而是"这种提交密度下 review 到底怎么做的"。链接：https://news.ycombinator.com/item?id=50456631
- **一个现实约束**：macOS / Windows 上目前必须装 Docker，Willison 希望未来能直接下发单二进制文件。链接：https://simonwillison.net/2026/Nov/11/aws-emulator/

> 观察：29,684 次提交不是成就，是**审计负担**。如果 AWS 内部没有一套"Agent 生成 → 自动验证 → 人类只审异常"的流水线，这个数字只会变成技术债。反过来说，如果它有，那这套流水线本身比模拟器更值钱。

### 5. Google 的一天：Gemini 4 Carbon 转正 + Decisions API + 机器人 + 基因

Google 在同一天做了四件事，把"模型公司"重新变回"平台公司"。

- **Gemini 4 Carbon 向所有人开放**：$2/$10 每百万 token，但 **12 月 1 日翻倍到 $4/$20**——这是明确的"抢份额期结束"信号。链接：https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/
- **Gemini Decisions API**：Gemini Decision 1 对文本/图像/音频/视频/PDF 一次返回最多 1000 个是/否、选项或评分问题的**校准概率**，$0.10/M 输入 token。链接：https://www.marktechpost.com/2026/11/11/google-gemini-decisions-api-gemini-decision-1/
- **Gemini Robotics 2.5 + ASIMOV-jailbreak 基准**：部分任务成功率翻倍，同时开源一个机器人安全越狱基准。链接：https://arstechnica.com/google/2026/11/deepmind-reveals-gemini-robotics-2-5-and-open-safety-benchmark-asimov-jailbreak/
- **AlphaGenome 2**：条件式 DNA 序列模型，可按细胞类型预测调控活性与变异效应，通过 API 开放非商业研究。链接：https://www.marktechpost.com/2026/11/11/google-deepmind-alphagenome-2-cell-type-variant-effects/
- **TPU 8i Max / 8tx 补全第八代产品线**：前者双芯封装主打长上下文 Agent，后者加硬件级机密推理，彭博称 2027 年可用。链接：https://www.marktechpost.com/2026/11/09/google-tpu-8i-max-tpu-8tx/
- **HN 141 分讨论 Decisions API**：社区最关心的是"校准概率"到底怎么验证，以及它和传统分类器/规则引擎的边界。链接：https://news.ycombinator.com/item?id=50456791

> 观察：Decisions API 是这条里最被低估的。它把 LLM 从"生成文本"改成"输出可评分的判断"，直接插进风控、审核、路由这些**原本属于传统 ML 的地盘**。$0.10/M 的定价意味着它想抢的不是 GPT 的活，是 sklearn 的活。

## 📊 论文精选

**1. ReTrace：把工具型 Agent 蒸馏成"无规划器"工作流**（arXiv 2611.14492）
企业流程自动化一遍遍跑同一个 SOP，但 Agent 每次执行都要调 LLM 选下一步，规模化后延迟与成本都不可接受。ReTrace 的做法是把 SOP + 少量历史执行日志转成**代码驱动**的可复用工作流：不再让 LLM 选步骤，而是从 Agent 每次工具调用时写下的"解释"里抽取判断条件，编译成分支逻辑。意义在于它把 Agent 从"运行时推理"变成"编译期产物"，是 Agent 落地企业的一条务实路径。链接：https://arxiv.org/abs/2611.14492v1

**2. Contrastive Discovery：让 LLM 在"互斥竞争解释"之间做实验**（arXiv 2611.14514）
现有科学发现 Agent 大多是逐点检验假设：证明 h 不成立，却不知道哪个替代解释成立。这篇提出把单假设换成**对比集**（一个科学问题 + 一组互斥且穷尽的竞争解释），每次实验按"能区分多少对竞争解释"来打分。这是一个干净的信息增益视角，对自动化实验设计（材料、生物、A/B 测试）都有直接借鉴价值。链接：https://arxiv.org/abs/2611.14514v1

**3. ARE-bench：在"真实研究现场"里考 Agent**（arXiv 2611.14364）
现有研究 Agent 基准大多是干净工作区里的独立任务，而真实研究是"项目进行到一半、目录里有失败版本和过期文件、请求依赖上次会话的决定"。ARE-bench 用真实研究者会话与工作区构建评测，考的是 Agent 能否在不破坏既有进展的前提下推进一步。这类基准比刷榜型 benchmark 更能预测实用价值。链接：https://arxiv.org/abs/2611.14364v1

**4. Earlybird：29M 参数的预测式流式识别**（arXiv 2611.14421）
常规流式 ASR 要等一个词说完（90–400ms）才输出。Earlybird 用"随机截断音频"训练，要求模型在词说到一半时就输出该词全文 + 猜下两个词，4 bit 量化后仅 16.8MB。对语音 Agent 来说这是实打实的端到端延迟收益。链接：https://arxiv.org/abs/2611.14421v1

**5. B3：重叠块去噪加速扩散语言模型**（arXiv 2611.14387）
块扩散的瓶颈是"每块只按最慢的 token 走，下一块必须等"。B3 让两个块在同一次前向里并行精修，并在线校准开块时机。这是扩散 LM 想真正挑战自回归的必经优化。链接：https://arxiv.org/abs/2611.14387v1

**6. 《AI 没变笨，是我们变挑了》**（arXiv 2611.14333）
用 Chatbot Arena 126 万次盲测投票（2023-05 至 2024-08），只取模型版本固定的配对，发现同一对模型"都说不好"的比例随时间上升——**评判者在变严，不是模型在变差**。这篇该被所有做主观评测的人读一遍。链接：https://arxiv.org/abs/2611.14333v1

## 💡 编者观察

第一件事证明 Agent 已经能产出**数量惊人**的代码；第二件事说明模型的产出质量高度依赖**它以为自己是谁**；第三件事则把模型从"生成器"改造成"判断器"。三条合起来指向一个结论：Agent 的瓶颈正在从"能力"迁移到"上下文与责任归属"。给 Agent 一个模糊的任务，它会给你 29,684 次提交和一屁股债；给它明确的边界和所有权，它才会去重构而不是堆叠。

第二个观察关于钱。OpenAI 单季 100 亿美元收入、Anthropic 1.4 万亿估值、TSMC 各投 10 亿、CoreWeave 开始要客户预付——这四件事放在一起看，是一个典型的**循环融资结构**：芯片厂投模型公司，模型公司买算力，算力公司拿合同去借钱，借来的钱再买芯片。这个结构在需求真实时是加速器，在需求见顶时是放大器。台积电入股这件事尤其值得警惕：供应商变成股东之后，"订单"和"投资回报"就不再是独立的两个数字。

第三个观察关于叙事。这周所有关于数据中心的新闻，本质上都是"AI 的成本被重新分配到具体的人身上"——电费单、地方选举、养老金收益率。技术圈习惯用"算力"讨论这件事，但选民只看得懂账单。这意味着接下来 12 个月，AI 行业最重要的能力可能不是训练更大的模型，而是**拿到电、拿到许可、并且让当地人觉得划算**。Gary Marcus 说 Anthropic 没有护城河，这话也许对，但更准确的说法是：这一轮真正的护城河在变电站和并网排队里，不在权重里。
