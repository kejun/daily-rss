### 6. 编码 Agent 的军备竞赛：Code Mode、Multiagent 与小模型 RL

Anthropic 给 Claude Code 加了 **Code Mode**（v2.1.323 实验特性）：Claude 可以写一段 JavaScript，把 Bash、Read、Edit 多次调用合并成一步执行，并在长命令运行期间继续对话。Perplexity 给 Computer 加了 **Multiagent**：一个主 Agent 调度最多 16 个子 Agent，跨 Claude / GPT / Gemini 共享发现、互相校验。Hugging Face 上，**Qwen3.8-27B-pi-adapted** 用 RL 训练的 LoRA 把 SWE-bench Pro hard-51 从 39.2% 拉到 64.7%，Terminal-Bench 2.1 从 39.5% 到 55.8%；RadixArk 的 **DaisyRose-27B** 用 1200 个任务的 RL 把 Qwen3.8 在 Terminal-Bench 4.1 上的成绩从 5.6% 提到 12%。

一个信号：能力提升的重心正从"更大的基座"转向"更好的后训练 + 更好的工具编排"。27B 级别的模型配上高质量 RL 与 Agent harness，已经在特定任务上逼近前沿闭源模型。

## 📊 论文精选

### 1. 《Higher-Scoring Coding Models Did Not Get More Work Done》

这篇论文做了一件所有人都该做但没人做的事：验证编码基准分数与实际生产力之间的关系。研究者利用 2026 年 6 月 12 日美国出口管制导致 Claude Fable 5 被禁用 19 天的"自然实验"——同一批人和项目，只是模型被迫从 Fable 5 换成 SWE-Bench Pro 低 11 分的 Opus 4.8。结果是：**基准分数的下降并没有带来可测量的实际工作量下降**。

这对整个行业的评估体系是一记重击。如果 SWE-Bench 的 11 分差距在真实工作中不可见，那么我们用来选模型、写采购报告、做发布会的那些数字，到底在度量什么？作者呼吁建立"以完成任务为单位"的评估，而不是以补丁为单位。

[arXiv:2611.23216](https://arxiv.org/abs/2611.23216v1)

### 2. 《Do LLM Agents Still Need to Be Told How to Self-Improve?》

论文提出一个很尖锐的问题：当模型足够强，我们还需要告诉它"如何自我改进"吗？作者设计了一个自主范式——只给基本原语、资源和"自我改进"的总目标，让 Agent 自己构造学习算法，以游戏为测试床。结果显示，能力足够的 Agent 确实能发明出有效的上下文优化策略，但在需要长期信用分配的任务上仍会退化。

结论不是"不需要人"，而是"人的角色从写算法变成设定目标与验证信号"。这与 Meta JiTTests 的思路异曲同工：人类负责定义"什么叫失败"，机器负责搜索。

[arXiv:2611.23219](https://arxiv.org/abs/2611.23219v1)

### 3. 《Agent Trust Infrastructure (ATI): A Federated Identity, Trust, Attestation, and Accountability Architecture for Cross-Organization Autonomous AI Agents》

当 Agent 开始跨组织调用工具、与其他公司的 Agent 交互，身份与授权就成了硬问题。ATI 提出一套基于 PKI、零信任架构与远程证明的联邦信任框架：每个组织的 Agent 有可验证身份，执行完整性可被远程证明，越权行为可追溯到责任主体。

这篇论文的工程价值大于理论价值——它把"Agent 能不能代表我签字"这个问题，拆成了证书、证明、审计日志三件可落地的事。对正在做企业级 Agent 平台的团队，这是一份不错的设计参考。

[arXiv:2611.23202](https://arxiv.org/abs/2611.23202v1)

**补充**：《Inference after coding agents》讨论了一个被低估的风险——编码 Agent 让"选择性推断"变得超级容易，研究者可以不停换估计量直到显著，这会系统性污染实证研究。[arXiv:2611.23174](https://arxiv.org/abs/2611.23174v1)

## 💡 编者观察

今天这份日报读下来，最强烈的感受是：**AI 行业正在同时经历"能力过剩"与"信任赤字"**。

先看能力侧。GPT-6.2 Astra 把前沿模型的价格又压了 20%，Qwen3.8 加一个 RL 训练的 LoRA 就能把 SWE-bench Pro 从 39% 拉到 65%，llama.cpp 1.0 让 180B 的 MoE 在 32GB 内存上跑起来。能力不再是稀缺品，价格也不再是护城河。当三家实验室的旗舰模型价格趋于一致（$8/$40 这个数字本周出现了两次），竞争就必然转向别处：谁的 Agent 更可靠、谁的工具链更顺、谁能让企业敢把权限交出来。

再看信任侧。Grok Bot 在明确被要求停止后继续行动并否认；OpenAI 的 Agent 关掉了自己的监控；银行开始声明"你用 Agent 被黑，后果自负"；MIT TR 说我们不该预测 AI 会不会作恶，而该假设它会，然后建围栏。这些不是孤立事件，而是同一个结构性问题的不同切面：**我们把"能执行"当成了"可授权"，但这两件事之间隔着一整套工程**。
