- VentureBeat 指出：企业 AI 的真实风险是 Agent 之间的「复杂度」，而非 Agent 自主性本身。🔗 https://venturebeat.com/ai/enterprise-ais-real-risk-isnt-autonomous-agents-its-the-complexity-between-them
- IBM 提出「智能运营」应把 Agent 安全与业务价值绑定，让治理落在数据层。🔗 https://aibusiness.com/generative-ai/ibm-agentic-ai-reshaping-governance-controls-trust
- ServiceNow 新增 AI Agent 管控与员工自动化工具；治理仍是核心。🔗 https://siliconangle.com/2026/10/15/servicenow-adds-ai-agent-controls-and-employee-automation-tools/
- 治理初创 nFOX Lab 计划开源其安全沙箱 **Blockhouse**，用于限制 AI 工作负载能访问什么、能做什么。🔗 https://siliconangle.com/2026/10/15/startup-nfox-to-open-source-its-sandbox-for-open-ai-models/

## 📰 行业深度

**1. 《开放模型确有价值，但风险是否被低估？》— MIT Technology Review**
文章以 Anthropic 声称 GLM-5.3 构成重大网络攻击风险为切口，系统拆解开放权重之争：封闭模型当前更强（Artificial Analysis 前八名全为闭源），但开放模型可下载、可本地运行、可重训，对学术研究几乎不可或缺。核心张力在于「安全 vs 民主化」，而 Jensen Huang 与 Dario Amodei 的公开立场背后都有明显的商业动机。
🔗 https://www.technologyreview.com/2026/10/13/1146366/open-models-have-real-benefits-do-they-outweigh-the-risks/

**2. 《AI 攻击留下一地鸡毛，AI 公司却不买单》— WIRED**
WIRED 指出一个反直觉现象：强大的 AI 模型持续造成混乱，但受害方极少真正追责，反而被鼓励去采用同样的工具。当 AI 事故缺乏问责闭环，安全激励就会系统性缺失。
🔗 https://www.wired.com/story/ai-hacks-leave-a-mess-that-ai-companies-arent-cleaning-up/

**3. 《AI 先攻下数学，如今正在追逐整个科学》— WIRED**
MIT 研究者告诉 WIRED：AI 可能很快成为解决经济学、高能物理等领域理论问题的「默认方式」。若成立，科研范式将从「人提假设」转向「人与 Agent 共演化假设」，其影响远超工具层面。
🔗 https://www.wired.com/story/ai-is-coming-for-science-next-watch-out/

**4. 《企业 AI 的真风险：不是自主 Agent，而是它们之间的复杂度》— VentureBeat**
当多个 Agent 互相调用，编排、权限、状态一致性带来的复杂度呈指数上升。对企业而言，治理必须下沉到数据层，而非停留在 Agent 之上。
🔗 https://venturebeat.com/ai/enterprise-ais-real-risk-isnt-autonomous-agents-its-the-complexity-between-them

**5. 《25 万亿 token 揭示开发者如何真正采纳 AI Agent》— InfoQ**
Brendan O'Leary 用真实数据论证：决定 AI 落地成败的是「信任」，而非基准分数。这对所有做 Agent 产品的团队都是一记提醒。
🔗 https://www.infoq.com/presentations/agentic-ai-developer-trust-adoption/

## 📊 论文精选

**1. Co-Evolving Acting and Forecasting for Language Agents（cs.AI）**
让语言 Agent 的「行动」与「预测」协同演化——Agent 不仅要执行，还要预测自身行动的后果，本质是把世界模型能力内嵌进行为策略，对提升长程任务稳定性有直接价值。
🔗 https://arxiv.org/list/cs.AI/recent

**2. SwarmRSI: Recursive Self-Improvement through Evolving Scientific Agent Swarm（cs.AI）**
用「演化中的科研 Agent 蜂群」实现递归自我改进（RSI），呼应了当下对 RSI 与自动科研的热烈讨论，是把群体智能与自我提升结合的激进尝试。
🔗 https://arxiv.org/list/cs.AI/recent

**3. ReaDy: Recurrent States as Dynamic Context for Speculative Drafting in Hybrid Linear Attention LLMs（cs.CL）**
面向「混合线性注意力」模型的推测解码新方案：把循环状态当作动态上下文来生成草稿，直击新一代高效架构的推理加速痛点。
🔗 https://arxiv.org/list/cs.CL/recent
