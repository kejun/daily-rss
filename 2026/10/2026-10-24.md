### 3. Questioning Instrumental Convergence in RLVR: Checkpoint Evidence from OLMo-3（arXiv 2610.31624）
"工具性趋同"（自保、攫取资源、欺骗）常被当作能力强化的必然后果。作者用 OLMo-3 的系列 checkpoint 做实证，检验 RLVR 训练过程中这些倾向是否真的单调上升。结论对 AI 安全叙事很重要：很多被当作"必然"的东西，可能只是"在某些设置下出现"。
<https://arxiv.org/abs/2610.31624>

## 💡 编者观察

今天所有新闻串起来，其实在讲同一件事：**AI 行业的瓶颈从"能力"迁移到了"账本"和"信任"。**

先看账本。OpenAI 用 1.25 万亿美元估值融 300 亿，这个数字本身不是新闻，新闻是它被定义为"IPO 前的过桥"。与此同时，MIT TR 提醒大家算存储，哈佛的研究提醒大家算 review，SiliconANGLE 用 Amdahl 定律提醒大家算流程里没被加速的那 90%。当资本端还在用"未来十年"定价，运营端已经开始用"这个季度"结账——这两套时间尺度的错位，会是 2027 年最危险的裂缝。

再看信任。今天 GitHub 涨得最猛的不是新模型，而是 Cloudflare 的安全审计 skill 和 NVIDIA 的 agent 运行时；1Password 给 agent 发"看不见密码"的登录凭证；Action State 开源 agent 行为校验工具；Google 给每个 agent 一台零凭证 microVM。这些产品解决的是同一个问题：**当我们把执行权交给模型，凭什么相信它？** 而另一边，PHP2Shell 的四天时间差、ConnectWise 被 AI agent 批量入侵、Meta Muse 分享链接泄露，说明这个问题的答案目前是"还不能"。

第三个观察关于开源。Kimi K3.1 Pro 先 API 后权重、DeepSeek 用 1521 tok/s 打速度、Interconnects 说"西方开源开始反击"——开源已经不是理想主义叙事，而是定价策略的一部分。承诺 11 月 4 日开源，本质上是用"未来会开放"换取当下的开发者注意力，这个承诺能不能兑现，比跑分更能定义一家公司的信用。

最后是人的一侧。Jim Nielsen 摘的那句"不要用必然性谈论 AI"，可能是今天最有用的一句话。技术新闻天然带着"这是大势"的语气，但 DEX 周刊里那位设计师的困惑——开源软件变多了，协作却消失了，大家都只信任自己和自己的 AI——才是真实的一线体感。效率工具让我们各自变强，也让我们越来越难一起做事。这不是技术问题，是组织问题，而组织问题从来不会被更好的模型自动解决。

明天值得盯的三件事：Kimi 权重是否如期、OpenAI 这轮融资的正式条款、以及 PHP2Shell 的补丁覆盖率。
