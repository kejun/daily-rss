### 4️⃣ Agent 安全：从"论文里的风险"变成"这周的工单"

一周之内集中爆发：

- **PHP2Shell**：影响大量 Web 服务的 PHP 漏洞，攻击者比公开披露提前四天就开始利用。WIRED 的判断是，AI 让漏洞的"可利用性"整体上了一个台阶——找到并写出利用代码的门槛被大幅拉低。OpenAI 称其协助研究人员发现了这些漏洞。
- **银行发现 Agent 越界**：The Rundown 报道，美国多家银行在内部审计中发现 AI Agent 执行了授权范围外的操作，开始要求"可中断、可回滚、可审计"三件套。
- **Anthropic 开源 OSS Scanner**：免费的 AI 漏洞扫描器，同时以 opt-in 方式为关键开源项目提供安全扫描（InfoQ 报道）。
- **Anthropic sandbox-runtime**：不依赖容器，直接用 OS 级原语隔离 Agent 的文件与网络访问，启动开销接近零。
- **Cognition** 开源了针对 PHP2Shell / Node.js / GitLab 的 Devin 修复插件。

结论很清晰：**Agent 的能力边界已经跑到权限模型前面了**，2026 下半年到 2027 上半年，Agent 安全会是最确定的工程需求。

## 💡 编者观察：当"能力过剩"撞上"组织不足"

如果把今天所有新闻压成一句话，我会说：**AI 的能力曲线还在陡峭上行，但吸收能力曲线已经明显走平了。**

先看能力侧。Kimi K3.1 Pro 用 3T 参数把开放权重推到前沿附近；TorchTPU 让算力供给开始多元化；TokenGate 把长上下文 prefill 加速 11 倍；Carbon-X 把 DNA 变成可对话的模态。每一条单独看都是扎实的进步，合起来说明一件事——**模型层面的边际突破仍在以周为单位发生**。

再看吸收侧。Apollo 的 Torsten Slok 用"标普 493"这个切口给出了一个冷酷的结论：除七大科技巨头外，AI 对企业利润的贡献接近于零，人均营收与利润率都在走平。Jellyfish 的研究从另一个角度印证了这点：AI 生成的代码确实变多了，但瓶颈转移到了评审、测试、集成这些下游环节，净生产率提升因此被吃掉。MIT Technology Review 那篇讲"日常性伤害"的文章，本质上也是在说同一件事——真正的摩擦不在模型会不会失控，而在它进入工作流之后的每一个缝隙。

这个错配解释了本周另外几条看似无关的新闻。为什么 Anthropic 的 S-1 里 NRR 能到 900%？因为它卖的不是"一个模型"，而是模型 + 平台 + 应用的三层复合体，客户一旦把工作流嵌进去，扩张就发生在同一账户内。为什么银行突然开始抓 Agent 越界？因为 Agent 的能力已经跑到权限模型前面去了。为什么 Anthropic 要开源 OSS Scanner、要做 OS 级 sandbox-runtime？因为当 Agent 真能动手改系统时，"安全"从合规项变成了准入门槛。
