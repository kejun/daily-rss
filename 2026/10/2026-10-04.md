## 📰 行业深度

### 1. 《别被骗了——LLM 不会推理》（MIT Technology Review）
AlphaGo 亲历者在 2016 年首尔见证「第五线落子」的震撼后，十年后冷峻断言：今天的 LLM 与当年那步棋的「理解」毫无关系。文章区分了**搜索+评估的真实推理**与**流畅的模式补全**，指出当前 agent 热潮建立在后者之上，警示行业别把流畅当智能。周末最值得细读的反方檄文。
→ https://www.technologyreview.com/2026/10/02/1145639/dont-be-fooled-llms-dont-reason/

### 2. 《Muse 给你所有亲友建了详细档案》（WIRED）
调查报道揭示 Meta Muse 的隐性代价：要让它替你办事，它就要理解你的人际关系网——于是数百万用户的亲友在不知情中被画像。文章追问：当「便利性」的抵押品是**第三方的隐私**，同意机制该如何设计？这是 agent 时代第一个大规模「旁观者隐私」案例。
→ https://www.wired.com/story/muse-creates-detailed-profiles-of-all-your-friends-and-family/

### 3. 《Meta、OpenAI、Uber 教会了 agent 先开口，那何时该闭嘴？》（MarkTechPost）
三个产品同押一个赌注：agent 主动说话。文章给出工程化答案——**只有当消息的期望价值超过打断成本时才发送**：价值由利害大小、行动概率、机会窗口、价值归属四要素构成；uplift 模型、contextual bandits、receptivity 模型这套增长团队老工具正好复用；Julia 1/Jev 这类 33ms 级决策模型负责「发不发」，LLM 只负责「怎么写」。主动式 agent 的教科书级框架。
→ https://www.marktechpost.com/2026/10/03/meta-openai-and-uber-just-taught-ai-agents-to-talk-first-what-about-when-to-stay-quiet/

### 4. 《DoorDash 如何构建内部 GenAI 平台》（InfoQ / QCon AI Boston 2026）
DoorDash 分享从 vendor-first 转向**开放权重模型**的架构抉择、LLM/agent 网关设计，以及在 5000+ 内部用户规模下平衡精度、延迟与成本的实战经验。配套阅读：Uber Eats 重建搜索管线把端到端延迟砍半，其中包含 agentic coding workflow 的落地。
→ https://www.infoq.com/presentations/doordash-genai-platform-architecture/ ｜ https://www.infoq.com/news/2026/10/uber-eats-search-latency/

### 5. 《Our AI Midwife》（Astral Codex Ten，HN 58 pts）
Scott Alexander 讨论 AI 在产科场景的落地叙事，延续其「AI 在具体高价值场景中静默改变专业实践」的观察线。

## 📊 论文精选

1. **AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents**（arXiv:2610.02163, cs.CL）
长程编码 agent 的上下文何时该压缩？本文把「压缩时机」变成可学习决策而非固定启发式，在长任务编码基准上显著提升成功率与成本效率——直击 Claude Code/Codex 类工具的真实痛点。
→ https://arxiv.org/abs/2610.02163

2. **LLM2Jev: LLMs Are Already Jev-Style Decision Models — When and How to Fine-Tune Them**（arXiv:2610.02076, cs.CL）

## 💡 编者观察

这个周末最值得玩味的，是「agent 主动性」从产品功能升格为**基础设施议题**的三连击。

第一击来自操作系统层。Apple 罕见地在权限公告里直接点名 AI agent：macOS 的 Full Disk Access 模型是「一次授权、永久全量」，这套为人类用户设计的信任假设，在 agent 时代成了系统性漏洞——你给编码 agent 磁盘权限，等于给一条看不见的供应链开门。Apple 的重构说明：平台方已经默认「未来每台 Mac 上都跑着若干 agent」。

第二击来自产品层。OpenAI 的 Dots、Meta 的 Muse、Uber 的司机助手，三家不约而同押注「agent 先开口」。MarkTechPost 那篇分析点破了关键：LLM 擅长写消息，却不该决定发不发——「何时打断用户」本质是 uplift 模型、bandit 和 receptivity 预测这套增长团队老手艺的回归。主动性的瓶颈从来不是生成能力，而是**打扰的定价**。这也解释了 Julia 1/Jev 这类 33ms 决策小模型为何突然走红，以及 arXiv 上 LLM2Jev 为何论证「LLM 本来就能当决策模型」。

第三击来自社会层。Muse 给亲友建画像的报道，是第一个大规模「旁观者隐私」案例：你同意了，但被你画像的几百个联系人没有。配合 Dense Discovery 引用的那句「p(doom) 很低，p(dystopia) 很高」——真正的风险不是觉醒的终结者，而是便利性一点一滴抵押掉第三方权利的日常。OpenAI 越狱门的诉讼与安全员工辞职，则是同一枚硬币的反面：能力跑得比治理快，账单总会寄到。

开源世界给出的答案朴素而具体：Trending 榜上 ponytail（让 agent 少写代码）、caveman（省 65% token）、claude-mem（持久记忆）、Agent-Reach（联网感知）——社区在用一个个小工具给 agent 补上「分寸感」。当巨头争论 agent 该多主动时，开发者在教 agent 何时闭嘴。这大概是本周最健康的信号。
