### 📖 On-Policy Distillation 方法论

Papers With Code 发布的 On-Policy Distillation 综述：通过学生模型自身策略采样轨迹，教师模型提供密集 token 级 KL 正则监督，有效关闭 off-policy 方法的训练-推理分布不匹配。统一了 forward-KL、reverse-KL、JSD 损失框架，reverse-KL 成为 mode-seeking 小学生的默认选择。只需在 Tinker 等 RL 栈上一行代码替换正则器即可实现。

🔗 [Papers With Code](https://paperswithcode.co/methods/on-policy-distillation)

## 📊 论文精选

### 1. Language Models Need Sleep (arXiv:2605.26099) ⭐⭐⭐⭐⭐

**核心发现：** Transformer 在长程任务中 attention 随上下文长度缩放不佳。本文提出一种"睡眠"整合机制——模型周期性地将近期上下文转换为持久 fast weights，然后清除 KV cache。睡眠期间执行 N 次离线循环传递，通过学到的局部规则更新 SSM 块的 fast weights。推理时将额外计算转移到睡眠阶段，保持清醒时预测延迟不变。在数学推理任务上，常规 Transformer 和 SSM-attention 混合模型均失败，而"睡眠"模型随 N 增大性能提升，深层推理任务增益最大。

🔗 [论文](https://arxiv.org/abs/2605.26099) · [PDF](https://arxiv.org/pdf/2605.26099) · [HTML](https://arxiv.org/html/2605.26099v1)

### 2. Negation Neglect: When models fail to learn negations in training (arXiv:2605.13829)

**核心发现：** 揭示了 LLM 训练中的一个关键缺陷——模型在训练过程中未能有效学习"否定"逻辑（negation），导致推理时对否定条件的理解不可靠。这对安全关键应用（如医疗、法律）有重要影响。

🔗 [论文](https://arxiv.org/abs/2605.13829)

### 3. TerminalWorld: Benchmarking Agents on Real-World Terminal Tasks (arXiv:2605.22535)

**核心发现：** 提出 TerminalWorld 基准，专门评测 AI Agent 在真实终端任务中的能力，覆盖文件系统操作、进程管理、网络调试等场景，为 Agent 能力评估提供了更贴近实际的标准。

🔗 [论文](https://arxiv.org/abs/2605.22535)

## 💡 编者观察

今天是信息密度极高的一天。几个关键信号值得特别关注：

**1. 融资与人才的"双高峰"叠加。** Anthropic $900B 估值 + Karpathy 加盟预训练团队，这两件事单独拿出来都是行业地震，叠加在一起则传递出一个明确信号：Anthropic 正在为下一轮预训练冲刺积蓄弹药。与此同时，OpenAI 内部 Greg Brockman 全面接管产品线，组织变革意味着内部资源正在重新聚焦。两巨头都在为"下一代模型"做最后布局。

**2. 编码 Agent 赛道进入"三国杀"阶段。** Cursor Composer 2.5（基于 Kimi K2.5 微调）、xAI Grok Build、Google Antigravity 2.0 三箭齐发，加上 Anthropic Claude Code 和 OpenAI Codex 持续领跑。Interconnects 的观察一针见血：开源模型至今仍没有等效的 agent 产品。这意味着未来 6-12 个月，高质量编程 agent 将是闭源模型的护城河。

**3. Gemini 3.5 Flash 的战略定位很有意思。** 它不是在绝对能力上挑战 Opus 4.7/GPT-5.5，而是在"速度-能力"甜点区建立优势。结合 Gemini Spark（常驻 Agent）和 Omni（多模态视频），Google 的策略更像是打造一个完整的 AI 基础设施栈，而非单点模型竞争。

**4. AI 安全与治理进入"硬约束"时代。** 从 Google SynthID 水印到英国 AISI 的自主黑客演示，再到美国 Take It Down Act 和教皇通谕，监管、技术防护、伦理讨论三个层面同步推进。MDASH 这样的 AI 安全工具本身也是 AI 构建的——"用 AI 治理 AI"正在成为现实。

**5. 论文层面，"Language Models Need Sleep" 是最有趣的一篇。** 将生物"睡眠-记忆整合"机制引入 Transformer 架构，思路新颖。如果能在实际推理中落地，可能为解决 context window 瓶颈提供一条不同于 attention 优化的路径。
