### 主题二：AI Agent 基础设施全面升级

各大公司加速构建 AI Agent 运行基础设施，从云端到终端全面铺开。

- **OpenAI 推出 WebSocket 执行模式**：OpenAI 为其 Responses API 引入 WebSocket 执行模式，通过持久连接替代 HTTP 请求-响应循环，将 Agent 工作流延迟降低多达 **40%**，显著改善编码 Agent 和实时 AI 系统的流式处理、工具执行和多步骤编排能力。[InfoQ](https://www.infoq.com/news/2026/05/openai-websocket-responses-api/)
- **Google Cloud Next '26：GKE Agent Sandbox + Hypercluster**：Google 在 Cloud Next '26 上发布 GKE Agent Sandbox（使用 gVisor 内核隔离实现安全 Agent 代码执行，每秒支持 300 个沙箱）和 Hypercluster（从单一控制平面管理百万芯片）。GKE Agent Sandbox 是目前三大超大规模云服务商中唯一的原生 Agent 沙箱。[InfoQ](https://www.infoq.com/news/2026/05/gke-agent-sandbox-hypercluster/)
- **Google 第八代 TPU 专为 Agent 和 SOTA 模型训练设计**：新一代 TPU 包含两颗专用芯片，加速模型训练和需要跨多个模型分布的持续多步推理和行动循环的 Agent 工作流，在性能、内存和能源效率方面均有提升。[InfoQ](https://www.infoq.com/news/2026/05/google-8th-tpu-generation/)
- **Anthropic 深入解析 Claude Code Auto Mode**：InfoQ 深度报道 Anthropic 的自主编码系统，包含人类审批门控机制，展示了从研究到执行的完整 Agent 工程实践。[InfoQ](https://www.infoq.com/news/2026/05/anthropic-claude-code-auto-mode/)
- **Anthropic 发布"自然语言自编码器"研究**：将 Claude 的"思维"转化为文本，通过可解释性研究揭示模型内部表示机制。[Anthropic Research](https://www.anthropic.com/research/natural-language-autoencoders) | [HN 讨论 (125 pts)](https://news.ycombinator.com/item?id=48052537)

### 1. LongSeeker：弹性上下文编排实现长程搜索 Agent

**arXiv:2605.05191** | **cs.AI** | 15 页

**问题**：长程搜索 Agent 在推理、调用工具和观察信息时工作上下文快速增长。简单累积所有中间内容会使 Agent 不堪重负，增加成本和错误风险。

**方案**：提出 **Context-ReAct**，一种通用 Agent 范式，将推理、上下文管理和工具使用集成到统一循环中。提供 5 个原子操作：Skip、Compress、Rollback、Snippet 和 Delete，允许 Agent 动态重塑工作上下文。

**结果**：基于 Qwen3-30B-A3B 微调的 LongSeeker 在 BrowseComp 上达到 **61.5%**，BrowseComp-ZH 上 **62.5%**，大幅超越 Tongyi DeepResearch（43.2%/46.7%）和 AgentFold（36.2%/47.3%）。

### 2. 首个 Token 就知道：单次解码置信度用于幻觉检测

**arXiv:2605.05166** | **cs.CL** | 6 页

**问题**：自一致性通过多次采样答案并测量一致性来检测幻觉，但需要重复解码且对词汇变化敏感。

**方案**：提出 **φ_first**，从单次贪婪解码中第一个内容承载答案 token 的 top-K logits 归一化熵计算置信度。

**结果**：在 3 个 7-8B 指令微调模型和 2 个基准上，φ_first 平均 AUROC 达到 **0.820**，超过语义一致性（0.793）和表面一致性（0.791）。建议将其作为采样不确定性估计前的默认低成本基线。
