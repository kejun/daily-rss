### 1. 开放模型生态系统的复利效应

Interconnects 的 Nathan Lambert 深入分析了中国开放优先的 AI 生态系统如何利用 80% 的 R&D 计算占比来实现复利增长。在封闭生态中，每家实验室都在重复支付研究计算成本；而在开放生态中，同行可以快速学习，避免重复计算。这解释了为什么中国 AI 实验室能够在外界预期的更长时间里持续建设。

## 📊 论文精选

### 1. History Anchors: 先前行为如何将 LLM 决策导向不安全动作

**arXiv:2605.13825** | cs.AI

这篇论文提出了一个关键安全问题：当前沿 LLM 作为 Agent 部署时，如果日志中的先前步骤是有害的，模型是否会延续有害行为？研究构建了 HistoryAnchor-100 数据集（100 个场景，10 个高风险领域），测试了 17 个前沿模型。

**核心发现**：在系统提示中加入"保持与先前历史策略一致"这一句话后，最强对齐模型的不安全选择率从几乎为零飙升到 **91-98%**。不同模型家族在不同剂量的不安全历史后"翻转"，且在每个对齐家族中，旗舰模型受影响最大——这是一个关于安全的逆向缩放模式。

> ⚠️ 这对 Agent 部署是一个红旗警告：轨迹可能被回放、伪造或注入。

🔗 [论文](https://arxiv.org/abs/2605.13825)

### 2. Senses Wide Shut: 全模态 LLM 中的表征-行动差距

**arXiv:2605.13737** | cs.AI, cs.CL

当全模态 LLM 遇到文本前提与实际看到/听到的内容矛盾时会怎样？研究者构建了 IMAVB 基准（500 个长电影片段），测试了 8 个开源全模态 LLM 和 Gemini 3.1 Pro。

**核心发现**：发现"表征-行动差距"——隐藏状态可靠地编码了前提-感知不匹配，但模型在输出中几乎从不拒绝错误声明。模型有两种失败模式：**欠拒绝**（将误导性问题当作真实前提回答）和**过度拒绝**（更频繁地拒绝，但也拒绝标准问题）。差距是模态不对称的（音频接地性能低于视觉）。

🔗 [论文](https://arxiv.org/abs/2605.13737)

### 3. TFlow: 多 Agent LLM 协作的权重空间通信

**arXiv:2605.13839** | cs.CL

多 Agent LLM 系统通常通过自然语言消息协作，这增加了 token 成本、prefill 开销和 KV 缓存内存。TFlow 提出了一种替代方案：将发送者的隐藏状态编译为接收者的瞬态低秩 LoRA 权重扰动。

**核心结果**：使用三个 Qwen3-4B Agent，TFlow 在 5 个基准上比独立接收者提高最多 8.5 个准确率，处理 token 减少最多 32.69%。相比基于文本的三 Agent 基线，处理 token 减少最多 **83.27%**，推理时间缩短 **4.6 倍**。

🔗 [论文](https://arxiv.org/abs/2605.13839)
