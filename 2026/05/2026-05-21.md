### 1. 生产级 LLM Agent 运行时架构模式选择方法论

**A Methodology for Selecting and Composing Runtime Architecture Patterns for Production LLM Agents** — arXiv:2605.20173

论文提出"随机-确定性边界"（SDB）概念：一个由提议者、验证者、提交步骤和拒绝信号组成的四部分契约，规定了 LLM 输出如何成为系统动作。围绕 SDB，将 Agent 运行时设计组织为协调、状态和控制三个关注点，提出了六种运行时模式（分层委托、分散-聚合+Saga、事件驱动排序、共享状态机、监督者+门控、人在回路）。还识别了一种名为"重放分歧"的失败模式。

→ [论文链接](https://arxiv.org/abs/2605.20173) | [代码仓库](https://github.com/vasundras/agent-runtime-patterns)

### 2. TIDE：MoE 扩散 LLM 推理的 I/O 感知专家卸载优化

**Efficient and Lossless MoE Diffusion LLM Inference with I/O-aware Expert Offload** — arXiv:2605.20179

针对扩散大语言模型（dLLMs）在 MoE 架构下的资源受限部署问题，提出 TIDE 推理系统。利用扩散过程中专家激活的时间稳定性，引入基于间隔的专家刷新策略，以 I/O 感知方式更新专家放置。无需模型训练的"免费午餐"加速方案，在 LLaDA2.0-mini/flash 模型上分别实现 1.4x 和 1.5x 吞吐量提升。

→ [论文链接](https://arxiv.org/abs/2605.20179)

### 3. 解耦感知与推理提升视觉语言模型后训练效果

**From Seeing to Thinking: Decoupling Perception and Reasoning Improves Post-Training of Vision-Language Models** — arXiv:2605.20177

研究发现 VLM 在视觉任务上的性能瓶颈主要在于视觉感知不足而非推理能力。提出将 VLM 后训练分解为三个阶段：视觉感知、视觉推理、文本推理。证明视觉感知应通过分阶段训练先巩固，再进行视觉推理精炼；且通过 RL 学习视觉感知比基于描述的 SFT 更有效。多 VLM 实验表明分阶段训练一致优于合并训练。

## 💡 编者观察
