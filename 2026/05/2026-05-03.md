### 主题六：LLM 服务架构新范式 — KV Cache、SMG 与评测瓶颈

LLM 部署基础设施持续演进，多个关键方向同时出现突破。

- **KV Cache 局部性成为隐藏成本变量**：相同 GPU 集群、相同模型、相同流量下，负载均衡器是否理解 token 局部性会导致吞吐量和延迟的显著差异。"平衡"与"高效"在面对数千 token 的缓存时是完全不同的概念。文章详细讨论了重新计算的成本、测量方法以及当负载均衡器理解 token 局部性时发生的变化。[Ranvier Systems](https://ranvier.systems/2026/04/30/kv-cache-locality-the-hidden-variable-in-your-llm-serving-cost.html)
- **PyTorch 团队发布 Shepherd Model Gateway (SMG)**：高性能模型路由网关，支持 SGLang、vLLM、TRT-LLM、OpenAI、Gemini 等后端，具备完整的 OpenAI 和 Anthropic API 兼容性。集中化管理 worker 生命周期，跨 HTTP/gRPC/OpenAI 兼容后端进行流量平衡。[PyTorch Blog](https://pytorch.org/blog/lightseek-smg/)
- **AI 评测正成为新的算力瓶颈**：Hugging Face 发表深度分析指出，随着模型能力的快速提升，评测所需的计算量正在成为制约模型迭代的关键因素。高质量的评测需要大量的推理 token，成本甚至可能超过训练阶段的部分开销。[HuggingFace Blog](https://huggingface.co/blog/evaleval/eval-costs-bottleneck)
