## 📊 论文精选

### 1. WorldString: Actionable World Representation (arXiv:2605.18743)
**标题**：Actionable World Representation

**摘要**：受大语言模型中涌现行为的启发，研究社区正在世界模型中追求类似的涌现能力，重点是物理世界建模。本文提出 WorldString，一种神经架构，能够从点云或 RGB-D 视频流中学习真实世界对象的状态流形。它作为物理世界模型的数字孪生，可无缝支持物理模拟、机器人操作和场景理解。

**意义**：这是将"对象"作为物理世界模型基本原语的统一建模方法，为机器人和具身智能提供了新的基础组件。

[论文链接](https://arxiv.org/abs/2605.18743) | [PDF](https://arxiv.org/pdf/2605.18743)

### 2. DashAttention: Differentiable and Adaptive Sparse Hierarchical Attention (arXiv:2605.18753)
**标题**：Differentiable and Adaptive Sparse Hierarchical Attention

**摘要**：现有分层注意力方法（如 NSA、InfLLMv2）使用 top-k 选择 KV 块，但假设相关 token 数量固定且阻碍了稀疏和密集阶段之间的梯度流动。本文提出 DashAttention，利用自适应稀疏 α-entmax 变换根据当前查询选择可变数量的块，保持整个层级完全可微。实验显示在 75% 稀疏度下达到与全注意力相当的精度，在长上下文建模上优于 NSA 和 InfLLMv2。

**意义**：为长上下文 LLM 提供了一种高效、可微的稀疏注意力方案，是降低推理成本的关键技术方向。

[论文链接](https://arxiv.org/abs/2605.18753) | [PDF](https://arxiv.org/pdf/2605.18753)

### 3. SkillGenBench: Benchmarking Skill Generation Pipelines for LLM Agents (arXiv:2605.18693)
**标题**：SkillGenBench: Benchmarking Skill Generation Pipelines for LLM Agents

**摘要**：随着 LLM Agent 越来越多地围绕可复用技能构建，核心挑战不再只是 Agent 能否使用提供的技能，而是能否生成正确、可复用、可执行的技能。SkillGenBench 提供了系统化的基准测试框架，评估不同技能生成管道的效果。

**意义**：Agent 技能自动生成是 Agent 从"手工艺品"走向"工业化生产"的关键一步，该基准为这一方向提供了标准化评估工具。

[论文链接](https://arxiv.org/abs/2605.18693) | [PDF](https://arxiv.org/pdf/2605.18693)

今天的信息密度极高，多条重量级新闻同时发生。Google I/O 2026 无疑是今天的绝对主角——Gemini 3.5 Flash、Gemini Omni、搜索框 25 年来首次大改，三管齐下，Google 正在全面展示其 AI 实力。值得注意的是，Google 这次不仅发布了新模型，更重要的是重新定义了搜索这个核心产品的交互范式：从"关键词 + 链接"到"多模态对话 + AI 摘要"，这是一次从底层架构到用户界面的全面重构。搜索框的改变可能是 Google 历史上最具深远意义的产品变更之一。

与此同时，AI 行业的人才流动也在加速。Karpathy 加入 Anthropic 是一个标志性事件——他曾在 OpenAI、Tesla、再回 OpenAI，现在选择了 Anthropic。这既是对 Anthropic 技术路线的认可，也可能预示着 AI 研发重心的某种转移。Karpathy 的"vibe coding"理念和对教育的持续热情，可能会在 Anthropic 产生独特的化学反应。

成本问题正在成为行业的"房间里的大象"。Ed Zitron 的长文《AI Is Too Expensive》直击要害：不管模型多强，如果推理成本不能降下来，商业化就是空中楼阁。DashAttention 等稀疏注意力论文的涌现，正是学术界对这一问题的回应——用更少的计算做更多的事。

开源生态方面，LangChain 正在构建一个完整的 Agent 工程平台，从 LangSmith Engine 到 SmithDB 再到 Sandboxes，每一步都在降低 Agent 开发和部署的门槛。当 Agent 从"玩具"变成"工具"，可观测性和调试能力就是最重要的基础设施。

一句话总结今天：**Google 重新定义搜索，Karpathy 重新定义阵营，而成本问题重新定义行业优先级。**
