## 📊 论文精选

### 1. OpenDeepThink: 基于 Bradley-Terry 聚合的并行推理
- **arXiv**: [2605.15177](https://arxiv.org/abs/2605.15177) | [PDF](https://arxiv.org/pdf/2605.15177)
- **核心贡献**：提出一种基于群体测试时计算扩展的推理框架。通过 LLM 对候选答案进行两两 Bradley-Terry 比较并聚合投票，选出最优解。在 8 轮迭代（约 27 分钟）中，将 Gemini 3.1 Pro 的 Codeforces Elo 提升 +405 分。该框架跨模型迁移无需重新调参，在 HLE 基准测试中，增益集中在客观可验证领域。同时发布了 CF-73——73 道专家级 Codeforces 题目数据集。

### 2. Is Grep All You Need? Agent Harness 如何重塑代理搜索
- **arXiv**: [2605.15184](https://arxiv.org/abs/2605.15184) | [PDF](https://arxiv.org/pdf/2605.15184)
- **核心贡献**：对 Agent 系统中 grep 与向量检索的系统性比较研究。在 116 个 LongMemEval 问题的测试中，使用 Chronos 自定义 Agent 和 Claude Code/Codex/Gemini CLI 进行实验。结果发现：在大多数情况下，grep 的准确率优于向量检索，但整体表现强烈依赖于 Agent 架构和工具调用风格。第二实验表明，随着无关对话历史的增加，检索策略的鲁棒性差异更加显著。

### 3. HuggingFace: Granite Embedding Multilingual R2
- **博客**: [详情](https://huggingface.co/blog/ibm-granite/granite-embedding-multilingual-r2)
- **核心贡献**：IBM 发布的开源多语言 Embedding 模型，Apache 2.0 许可，支持 32K 上下文窗口。在亚 100M 参数规模下实现了最佳检索质量，适用于多语言 RAG 场景。
