## 📊 论文精选

### 1. OpenDeepThink: 基于 Bradley-Terry 聚合的并行推理

提出一种基于群体的测试时计算框架，通过成对 Bradley-Terry 比较来选择最佳推理候选。LLM 对候选对进行评判，通过 Bradley-Terry 聚合成全局排名。在 Gemini 3.1 Pro 上，经过 8 轮顺序 LLM 调用（约 27 分钟），Codeforces Elo 提升了 405 分。该管道可在不同强度模型间迁移而无需重新调参。

> 🔗 [arXiv:2605.15177](https://arxiv.org/abs/2605.15177) | [PDF](https://arxiv.org/pdf/2605.15177)

### 2. APWA: 可并行化 Agent 工作流的分布式架构

提出 Agent-Parallel Workload Architecture，一种用于高效处理高度可并行化 Agent 工作负载的分布式多 Agent 系统架构。APWA 通过将工作流分解为非干扰子问题来实现并行执行，每个子问题使用独立资源处理而无需跨通信。
