## 📊 论文精选（3 篇）

### 1. MUSE-Autoskill：通过技能创建、记忆、管理与评估实现自演进 Agent
- **arXiv:** [2605.27366](https://arxiv.org/abs/2605.27366)
- **摘要：** 提出 MUSE-Autoskill Agent 框架，让 Agent 通过统一的技能生命周期（创建、记忆、管理、评估、优化）持续提升任务解决能力。引入技能级记忆，在每次任务中为每个技能积累经验，实现更有效的复用和适应。SkillsBench 实验表明，生命周期管理的技能可提高任务成功率、效率、复用率和跨 Agent 迁移能力。
- **亮点：** 首次将技能视为"长期的、有经验的、可测试的资产"，而非孤立静态的工件。

### 2. 多 Agent LLM 系统用于自动化漏洞发现与复现
- **arXiv:** [2605.21779](https://arxiv.org/abs/2605.21779)
- **摘要：** 利用多 Agent 系统自动发现和复现安全漏洞，结合 HN 讨论热度（34 points）显示该方向受到安全社区关注。
- **亮点：** 将 Agent 技术应用于网络安全，实现从漏洞发现到复现的全自动化。

### 3. ITBench-AA：前沿模型在企业级 IT Agent 任务中得分低于 50%
- **来源：** [HuggingFace / IBM Research / Artificial Analysis](https://huggingface.co/blog/ibm-research/itbench-aa)
- **摘要：** IBM Research 与 Artificial Analysis 联合发布首个针对 Agentic 企业 IT 任务的基准测试。所有前沿模型得分均低于 50%，说明 Agent 在企业真实 IT 运维场景中的能力仍有巨大提升空间。
- **亮点：** 首个企业 IT Agent 基准，揭示了前沿模型与实际应用之间的显著差距。
