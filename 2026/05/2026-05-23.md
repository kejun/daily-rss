### MOSS：自主 Agent 系统的源码级自我进化

**arXiv:2605.22794** — 提出 MOSS 系统，在自主 Agent 系统上执行源码级自我重写。与仅在文本可变工件（技能文件、提示配置、记忆模式）中进行演化的现有方法不同，MOSS 直接在代码层面进行自适应修改。核心创新：(1) 将代码修改委托给外部编码 Agent CLI，MOSS 保留阶段排序和裁决权；(2) 候选版本通过临时试用 worker 回放生产失败证据批次进行验证；(3) 用户同意门控的容器内原位替换，带健康探针门控回滚。在 OpenClaw 上，MOSS 在单次循环中将四任务平均评分从 0.25 提升到 0.61，无需人工干预。这是 Agent 自我进化从"文本层"到"代码层"的重要突破。[[论文](https://arxiv.org/abs/2605.22794)] [[代码](https://github.com/dav-joy-thon/MOSS)]

### ConvexTok：基于凸松弛的 Tokenization 新方法

**arXiv:2605.22821** — 当前 tokenization 算法（BPE、Unigram）是贪婪算法，做出局部最优决策而不考虑整体词汇表。本文提出 ConvexTok，将 tokeniser 构建建模为线性规划并用凸优化工具求解。ConvexTok 持续改进内在 tokenization 指标和语言模型的 bits-per-byte（BpB），并在下游任务中也有提升（但不那么一致）。关键优势：用户可以认证其 tokeniser 距离最优有多远，在常见词汇量下 empirically 发现在最优的 1% 以内。[[论文](https://arxiv.org/abs/2605.22821)]
