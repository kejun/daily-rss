### 2. Anthropic 政策风波：从"暗中破坏"到公开透明

Anthropic 遭遇了一场开发者信任危机。此前，该公司被发现**暗中将 Claude Fable 5 用户针对特定任务（训练竞争模型、调试 AI 代码、优化神经架构）的请求降级到更弱模型**，且用户完全不知情。这一做法引发了研究社区的强烈反弹——研究者发现自己不仅浪费了 Token 和资金，还得到了非预期的降级结果。

### 深度 1：算力能否商品化？CoreWeave 的"非标品"叙事

CoreWeave 联合创始人 Brannin McBee 提出了一个 provocative 的观点：**算力不像石油或小麦那样可以商品化**，因为不同的硬件架构、网络拓扑、软件栈和数据中心位置组合产生了实质性的差异化。HN 社区对此进行了激烈讨论。

这篇文章的核心洞察是：CoreWeave 表面上在说"算力不是商品"，实际上是在**给非商品定价**，并揭示市场中仍然隐藏的利差空间。在 NVIDIA GPU 供应持续紧张、云厂商竞相扩建数据中心的背景下，这个问题的答案将直接影响 AI 基础设施投资的长期回报预期。

## 📊 论文精选

### 1. Agents-K1: Towards Agent-native Knowledge Orchestration

**摘要**：当前的 LLM 研究 Agent 虽然在 Agent 编排方面取得进展，但大多忽视了**科学知识编排**。现有工作通常将论文简化为摘要和扁平的引用关系，丢失了科学推理所需的关键实体、主张、证据和方法谱系。

Agents-K1 引入了一个端到端知识编排管道，将原始文档转化为 Agent 原生的科学知识图谱。核心组件包括：
- **多模态解析器**：五模块 schema 捕获实体、多模态证据、引用和类型化实体间关系（覆盖全文而非仅摘要）
- **4B 信息提取骨干**：使用 GRPO + 基于规则的奖励训练
- **graphanything CLI**：三源 Agent 接口，统一 Web 搜索、多模态图检索和跨文档遍历

该系统已处理 **246 万篇**科学论文（覆盖 6 个学科），产出了 **Scholar-KG** 知识图谱，并释放了 100 万篇的子集。

### 2. Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments

**摘要**：LLM Agent 在各类基准测试中表现出色，但大多数评估假设环境是静态的。现实世界的部署本质上是动态的，需要 Agent 不断调整其知识、技能和行为以适应变化的环境。

作者提出了 **EvoArena** 基准套件，将环境变化建模为跨终端、软件和社交领域的渐进式更新序列。同时提出了 **EvoMem**——一种基于补丁的记忆范式，将记忆演化记录为结构化更新历史。

实验结果表明：当前 Agent 在 EvoArena 上的平均准确率仅为 **39.6%**；EvoMem 在 EvoArena 上平均提升了 **1.5%**，在 GAIA 和 LoCoMo 基准上分别提升了 **6.1%** 和 **4.8%**。

- [论文链接](https://arxiv.org/abs/2606.13681)

### 3. Learning to Reason by Analogy via Retrieval-Augmented Reinforcement Fine-Tuning

**摘要**：传统的检索增强生成（RAG）基于词汇或语义相似度的检索方式不适合复杂推理任务。作者提出了 **RA-RFT**（检索增强强化微调），教语言模型通过类比进行推理。

RA-RFT 使用黄金相关性蒸馏来训练检索器，按**预期推理收益**而非语义重叠度对上下文进行排序。在数学推理基准上，RA-RFT 在 Qwen3-1.7B 和 Qwen3-4B 上分别比标准 GRPO 提升了 **7.1** 和 **2.8** 个 AIME 2025 分数点。

## 💡 编者观察

今天是 AI 行业一个值得记住的周六。几个看似独立的事件，实际上正在勾勒出一条清晰的主线：**AI Agent 正在从"单次对话"走向"持久工作"**。

OpenAI 收购 Ona 是这个趋势的最强信号。Codex 不再只是一个代码补全工具——它要成为一个能持续工作、跨会话记忆、在客户可控的云端环境中执行复杂工程任务的持久 Agent。小米的 MiMo Code 用跨会话记忆系统击败了 Claude Code，这进一步验证了"记忆连续性"是 Agent 能力的核心分水岭。

与此同时，Anthropic 的透明度危机给我们提了一个醒：当 Agent 变得越来越自主和强大时，**用户对"Agent 在做什么"的知情权**与"AI 公司的商业安全"之间的矛盾会越来越尖锐。Anthropic 最终选择公开其安全策略，这是一个正确的决定——在 Agent 时代，透明度不再是可选项，而是信任的基础设施。

另外值得关注的是算力商品化的讨论。CoreWeave 的观点看似在为自己的商业模式辩护，但它触及了一个更深层的问题：**AI 基础设施是否最终会成为像电力一样的公用事业？** 如果算力真的无法商品化，那么 AI 行业的竞争格局将比我们想象的更加分散——不同硬件、不同软件栈、不同数据中心的组合将创造出一个高度差异化的市场，而不是赢家通吃。

最后，2029 年 Mythos 级开源模型的预测如果成真，将是 AI 民主化的终极里程碑。当任何人都能在 16GB RAM 的设备上运行 Claude Fable 5 级别的模型时，我们今天讨论的所有"护城河"——算力、数据、模型规模——都将变得毫无意义。**真正有价值的，将是如何在已有模型之上构建独特的应用和体验。**

这就是未来三年的游戏。我们正在进入一个 AI 能力不再是稀缺资源的时代——**稀缺的将是好的想法、好的执行力和好的分发渠道**。
