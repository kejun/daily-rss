### 1️⃣ 美国政府拟持股 OpenAI — AI 与国家利益的第一次深度绑定

白宫与 OpenAI 正在讨论一项可能由美国政府持有 OpenAI 1-5% 股权的交易方案，股份将纳入拟议中的"公共财富基金"（Public Wealth Fund），让普通美国民众分享 AI 革命的经济红利。

- Sam Altman 上周分别与参议员 Bernie Sanders 和特朗普政府官员会面讨论该方案

**深层分析：** 这在西方政治光谱中是一个极为罕见的跨党派议题——右翼希望"让美国人民变富"，左翼希望"财富再分配"，但反对者担忧的是政府既当股东又当监管者的利益冲突。[CNBC 原文](https://www.cnbc.com/2026/06/05/trump-open-ai-altman-stake.html) · [Axios 报道](https://www.axios.com/2026/06/06/trump-us-stake-ai-companies) · [The Rundown AI 深度解读](https://www.therundown.ai/p/washington-wants-a-piece-of-openai)

### 3️⃣ AI 行业经济账：每收你 100 美元，实际花费超 1,000 美元

一份来自 EA Research 的深度分析揭示了前沿 AI 实验室令人震惊的成本结构：OpenAI 和 Anthropic 可能每从用户处收取 100 美元收入，实际支出超过 1,000 美元。

- LLM 辅助编码目前之所以"便宜"，是因为订阅价格被严重补贴
- 需要多轮循环和"思考"的 API 调用已经变得极其昂贵
- 开发者需要为成本持续上升做准备，构建更有韧性的系统
- Anthropic 已做出总计约 3,750 亿美元的算力和芯片承诺（Google、Amazon、Microsoft 共 3,300 亿 + CoreWeave 300 亿 + SpaceX 150 亿）

- Gary Marcus 评论："如果生产力提升未能实现，当前的建设将成为历史上最大规模的资本错配"

## 📊 论文精选

### 1. How AI Agents Reshape Knowledge Work: Autonomy, Efficiency, and Scope

**arXiv:2606.07489** · Perplexity 团队

利用 Perplexity 的 Search 和 Computer 产品的生产数据，研究了 AI Agent 如何加速和重塑知识工作。三个关键发现：
- Computer 每次用户会话执行 26 分钟自主工作（Search 仅 33 秒），将用户后续查询分布向更高层级工作转移
- 将匹配任务的完成时间从 269 分钟缩短至 36 分钟，降低时间和成本 87% 和 94%
- Computer 改变了用户尝试的工作范围：更多跨职业边界的查询、更高层级认知任务、复合任务

[→ 论文](https://arxiv.org/abs/2606.07489)

### 2. Act As a Real Researcher (AARR) — AI Agent 能像真正的研究者一样工作吗？

**arXiv:2606.07462**

提出 AARR 基准系列，首个子基准 AARRI-Bench（Act As a Real Research Intern）评估前沿模型和 Agent 系统在精细化研究场景中的表现。即使在最佳配置下（Mini-SWE-Agent + Claude Opus 4.7），成功率也仅为 68.3%，经常忽视对人类研究者来说显而易见的微妙但关键的细节。

[→ 论文](https://arxiv.org/abs/2606.07462)

### 3. Long-Term Life Simulation and Learning in Agent Societies (Agentopia)

**arXiv:2606.07513**

提出 Agentopia 框架，在 100 个 Agent 的多 Agent 社会中进行长达 10 年的模拟生活。Agent 自主追求个人成长、发展社会关系并满足需求。定义了生活奖励来反映人类幸福感，并通过拒绝采样训练 LLM。

[→ 论文](https://arxiv.org/abs/2606.07513)

### 4. LLM 概率推理能力评估：掷骰子测试

**arXiv:2606.07515**

通过受控基准研究评估 8 个最先进的 LLM 在离散概率问题上的表现。在标准问题上平均准确率达 0.96，但在反直觉问题上仅 0.59。发现 token 偏见：当标准表述被替换为伪装变体时，性能下降超过 20%。

[→ 论文](https://arxiv.org/abs/2606.07515)

### 5. EmbedFilter：LLM 文本嵌入的隐式过滤器

**arXiv:2606.07502**

发现 LLM 的非嵌入矩阵中存在潜在空间，会主动将高频 token 写入嵌入空间。通过过滤该子空间，EmbedFilter 抑制高频 token 影响，在显著降低嵌入维度的同时保持语义质量。
