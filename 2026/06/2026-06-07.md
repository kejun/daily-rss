### 主题一：OpenAI 法律战落幕，IPO 倒计时

OpenAI 与 Elon Musk 的旷日持久的法律纠纷终于有了定论，与此同时公司上市步伐加速。

- **Musk 1500 亿美元诉讼被驳回：** 加州奥克兰联邦法院陪审团在不到两小时审议后，一致驳回了 Elon Musk 对 OpenAI、Sam Altman 和 Greg Brockman 的 1500 亿美元诉讼。九人陪审团认定，Musk 的违反慈善信托和不当得利主张分别受到两年和三年诉讼时效限制——他早在 2021 年就已知晓 OpenAI 向营利性结构转型，却直到 2024 年才提起诉讼。主审法官 Yvonne Gonzalez Rogers 最终完全驳回了此案。这是 AI 行业最具影响力的法律战之一，标志着 OpenAI 扫清了上市前的最大障碍。[[NYT](https://www.nytimes.com/2026/05/18/technology/elon-musk-lawsuit-openai-sam-altman.html)] [[BBC](https://www.bbc.com/news/articles/cewpyv79pw1o)] [[The Verge](https://www.theverge.com/tech/917225/sam-altman-elon-musk-openai-lawsuit)]
- **OpenAI 准备 IPO 申请：** 据《纽约时报》报道，OpenAI 正在准备在未来几周提交上市申请。Musk 案的结束消除了最大的法律不确定性。如果成功上市，OpenAI 将成为有史以来规模最大的科技公司 IPO 之一，估值可能超过 3000 亿美元。[[NYT](https://www.nytimes.com/2026/05/20/technology/openai-ipo.html)]

### 2. CLSA：跨层稀疏注意力机制，7.6 倍解码加速

**论文：** [You Only Index Once: Cross-L-layer Sparse Attention with Shared Routing](https://arxiv.org/abs/2606.06467)

**摘要：** 现代 LLM 的长上下文推理越来越受到解码效率的制约。本文提出跨层稀疏注意力（CLSA），基于 KV 共享架构（如 YOCO），核心思想是：不仅跨跨解码器层共享 KV 缓存，还共享路由索引。单个索引器一次性计算 token 级 top-k 选择，并在所有层复用该索引，保留了 token 稀疏注意力的细粒度选择性，同时摊销了路由开销。在 128K 上下文下实现 7.6 倍解码加速和 17.1 倍整体吞吐量提升。

**为什么值得关注：** 长上下文 LLM 的效率瓶颈是行业共识。CLSA 提供了一种"索引一次，多层复用"的优雅方案，在保持精度的同时大幅提升速度。对于需要处理超长上下文的场景（文档分析、代码理解），这是值得关注的基础架构优化。

### 3. SARDI：扩散语言模型的自我增强检索

**论文：** [Self-Augmenting Retrieval for Diffusion Language Models](https://arxiv.org/abs/2606.06474)（ICML 2026）
