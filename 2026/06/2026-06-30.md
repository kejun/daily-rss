## 📊 论文精选（3 篇）

### 1️⃣ Agent-Native Immune System (ANIS) — Agent 原生免疫系统

- **arXiv:** [2606.28270](https://arxiv.org/abs/2606.28270) | cs.AI
- **核心贡献：** 提出首个嵌入 Agent 认知循环内部的内生防御架构。设计六层 Immune Tower（L0-L5），包含 Barrier Immunity 物理/逻辑隔离层。建立 Agent 病毒/疫苗统一分类体系。提出 Harness Triad（Meta/Self/Auto）自监控框架驱动持续免疫学习。
- **关键区分：** 模型对齐（alignment）是训练期的静态「宪法」，ANIS 是运行时的动态「执法」机制。
- **意义：** 为 AI Agent 安全提供了全新的研究方向，从「外部边界防御」转向「内生免疫系统」。

### 2️⃣ Tandem Reinforcement Learning (TRL) — 串联强化学习

- **arXiv:** [2606.28166](https://arxiv.org/abs/2606.28166) | cs.AI
- **核心贡献：** 将 tandem training 范式引入 RLVR 流程。训练时更强的 senior 模型和冻结的 junior 模型交替协作生成推理链，共同获得奖励。在 Qwen3-4B-Instruct 上验证：TRL 在 solo 推理能力上匹配 vanilla GRPO，同时涌现三个特性：更强的 junior 交接鲁棒性、减少分布漂移、对 junior 更可读的推理链。
- **意义：** 为多模型协作和人类兼容性提供了可行的 RLVR 路径。

### 3️⃣ Vision-Default, Prior-Override — VLM 感知-知识冲突的因果机制

- **arXiv:** [2606.28273](https://arxiv.org/abs/2606.28273) | cs.CL
- **核心发现：** 在三种 VLM 家族中发现：视觉接地是默认行为，而先验知识接地依赖网络后半部分集中的一小批因果必要注意力头（仅 2.5-4.8%）。消融这些头可在 68-96% 的情况下将知识接地预测翻转为视觉接地预测，但对视觉接地预测仅影响 0.8-7.5%——揭示不对称的因果结构。
- **意义：** 首次在组件级别揭示 VLM 如何处理视觉证据与记忆知识的冲突，为多模态系统可靠性提供理论支撑。

## 💡 编者观察

今天的信息面最突出的信号是：**AI Agent 正在从「概念验证」大步迈向「工程化生产」**。

Vercel 的 Eve 框架用文件系统定义 Agent 行为、LangChain 的动态子 Agent 让 Agent 编排更加灵活、Google OpenRL 把 RL 微调的门槛降到 Kubernetes 级别——这三件事放在一起看，方向非常清晰：Agent 开发的门槛在快速降低，而生产化能力在快速增强。这意味着未来 6-12 个月，我们会看到大量 AI Agent 从实验室走向真实业务场景。

但 GitLab 的报告给出了冷静的反面视角：AI 加速了编码，但没有加速交付。这是一个极其重要的信号——它告诉我们 AI 带来的效率提升正在被 SDLC 下游环节吸收。这不代表 AI 没有价值，而是提醒我们：**瓶颈转移了，我们需要系统性思维。** 如果你只引入 AI 编码助手而不优化测试和审查流程，你只是在把拥堵从一段路挪到了另一段路。

开源模型生态的多元化同样值得持续关注。NVIDIA 采用 OpenMDW 许可证而非自定义许可，这是一个积极的信号——它意味着大厂开始认真对待模型权重的开源治理。而 Zyphra 在 AMD GPU 上训练模型、Poolside 专注于代码模型，都说明「长尾化」和「专业化」正在成为开源模型的主流趋势。未来可能不再是几家大厂包揽一切，而是大量公司在各自领域深耕。

最后，ANIS 论文提出的「Agent 原生免疫系统」概念很有启发性。当 Agent 获得越来越多的自主权——记忆、工具调用、多 Agent 协作——传统的边界安全模型完全失效。我们需要的是嵌入 Agent 认知循环内部的内生安全机制。这与 InfoQ 圆桌讨论的结论不谋而合。**安全不能是事后补丁，必须是架构设计的一部分。**
