### 主题 4：Agent 记忆与"持久化计算机"——Agent 基础设施进入"有状态"时代
两条基础设施新闻指向同一方向：**Agent 正在从"无状态工具"走向"有状态实体"**。其一，**腾讯云开源 TencentDB Agent Memory v2.0**，一个团队级 Agent 记忆中枢，把对话/文档/代码转化为 Chat Memory、Skill、LLM-Wiki、Code-Graph 四类受治理资产，MIT 协议、Docker 自托管，支持 Claude Code、OpenClaw、Hermes 等集成。其二，**Cloudflare 推出 Cloudflare Computer**，一个开源运行时，给 Agent 提供"真正的计算机"而非短暂容器，基于 Isolates 实现快速 serverless 执行。**"记忆"与"持久化"成为 Agent 迈向生产级的关键地基。**

### 主题 5：企业 AI 落地真相——"更好的模型"已不够用

- → [AI Business: Prompt: Why Better AI Models Aren't Enough](https://aibusiness.com/generative-ai/prompt-why-better-ai-models-aren-t-enough)
- → [AI Business: Build Vs. Buy: The AI Agent Landscape for Businesses](https://aibusiness.com/generative-ai/build-vs-buy-ai-agent-landscape-businesses)
