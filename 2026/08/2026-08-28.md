### 2. 🦾 Anthropic 发布 Model Hardware Standard：给 AI Agent 一把「物理世界的钥匙」

- **Anthropic 开放 Model Hardware Standard（MHS）研究预览**：一套让 AI Agent 安全操作物理设备的共享规范——显微镜、液体处理器、机械臂、量子计算硬件、制造机器，Agent 可并行操作多台设备，完成从常规药物发现实验到量子计算机激光校准的复杂任务。MHS 源自 Anthropic 与 HHMI Janelia 研究园区（生命科学顶级机构）的合作。[Anthropic 官方](https://www.anthropic.com/news/model-hardware-standard-research-preview) ｜ [HN 讨论](https://news.ycombinator.com/item?id=49468834)

- **MHS 怎么工作**：标准化驱动层用 read/write 原语（「读取温度」「设置温度」）让设备互通；设备以标准格式可被发现；自然语言标签让用户把「机械臂重量」这类手册里的隐性知识直接写进驱动，Agent 据此生成参考文件学会操作陌生设备；控制走 MCP、CLI、代码文件三条通路。Anthropic 观察到 Claude 会像科学家一样探索性地调整激光、通过相机观察结果迭代、最后打包成确定性脚本——「闭环实验自动化」已经跑通。[Anthropic 官方](https://www.anthropic.com/news/model-hardware-standard-research-preview)

- **安全先行、模型无关**：MHS 先与科学/机器人/电子/制造领域的可信伙伴共建安全评估与最佳实践，之后再开源；标准与模型无关，任何 agent harness 都可用 MCP 访问。WIRED 分析：把 Agent 从屏幕放进实验室是双刃剑——加速科研的同时也带来生物武器等滥用风险，Anthropic 称护栏在模型内部。[WIRED](https://www.wired.com/story/anthropic-standard-ai-agents-coming-to-the-physical-world/) ｜ [申请研究预览](https://www.modelhardwarestandard.com/)

第二条主线是 Agent 正在从屏幕走向物理世界。Anthropic 的 Model Hardware Standard 把 Agent 送进实验室和工厂，OpenAI 的 Persistent mode 让 Agent 从「应答式」变成「常驻式」，而这边厢 100 多家公司联合呼吁防御 rogue AI——能力的边界和安全的风险在同一天被同时推进。MHS 选择与生命科学机构 HHMI 合作、先做安全评估再开源，节奏上是谨慎的；但 WIRED 提出的生物武器风险、以及昨日 Hugging Face 攻击事件中「模型被训练成作弊者」的教训，都提醒我们：每一项让 Agent 更强大的能力，都会同步放大其失控时的破坏半径。物理世界没有 rollback。

第三条是「小模型经济学」的暗流。HN 343 分的那篇《Small Models Have Arrived》用 0.10 美元一次请求算清楚了消费级 AI 的账；Perplexity 的 Portable Computer、Unsloth desktop、Granite 4.2 则从产品侧把「本地运行」做成了正经生意。当推理成本从 1 美元降到 0.1 美元，消费级 AI 创业的 unit economics 第一次成立——投资者「为什么没有更多消费级 AI 公司」的困惑，答案可能正在被小模型改写。
