今日最大新闻：DeepSeek 正式发布 V4 预览版，包含两个 MoE 模型——V4-Pro（1.6T 总参数 / 49B 激活）和 V4-Flash（284B 总参数 / 13B 激活），均支持 100 万 token 上下文窗口。V4 的核心创新在于其混合注意力机制（CSA + HCA），在 1M 上下文下推理 FLOPs 仅为 V3.2 的 27%，KV Cache 占用仅为 10%。相比 GQA-8 架构，V4 的 KV Cache 仅为其 2%。这使得 V4 成为目前最适合长时间 Agent 任务的开源模型。定价方面，V4-Pro 输入 $1.74/M tokens，V4-Flash 低至 $0.14/M tokens，性价比极高。

## 💡 编者观察

今天的信息流传递了一个清晰的信号：**AI 行业正在从"能力竞赛"转向"效率竞赛"**。

DeepSeek-V4 的发布是这一转折的标志性事件。它不是在基准分数上碾压对手——事实上它的 SOTA 成绩并不突出——但它解决了一个更根本的问题：如何让百万级上下文窗口在实际 Agent 任务中可用。KV Cache 压缩到 GQA-8 的 2%，推理 FLOPs 降到 V3.2 的 27%，这些数字意味着 V4 可以在消费级硬件上运行超长 Agent 任务。当 OpenAI 和 Anthropic 还在为 128K 上下文的推理成本头疼时，DeepSeek 已经让 1M 上下文变得经济可行。

与此同时，融资数据揭示了行业的另一个现实：资本正在疯狂涌入 AI 基础设施层。Q1 2026 的 3000 亿美元融资中，绝大部分流向了算力、模型训练和底层工具。Cognition 和 Cursor 的估值分别达到 250 亿和 500 亿美元，说明市场相信"AI 编程"是离钱最近的落地场景。但这也带来一个隐忧——当 90% 的资本集中在基础设施层，应用层的创新是否会因为资源不足而滞后？

Claude Code 生态的爆发（GitHub Trending 前三占两席）和 Agent 可靠性问题（HN 上 Claude 4.7 hooks 讨论）形成有趣对比：一方面 Agent 工具链正在成熟，另一方面基础模型的指令遵循能力仍然是瓶颈。这或许解释了为什么 Anthropic 在 Opus 4.6 上投入了混合 MoE 架构——当 Agent 任务复杂度超过单一 Transformer 的容量时，路由机制成为必然选择。

最后，LLM 推理成本下降 50% 的趋势值得所有 AI 创业者关注。当"足够好"的推理成本降到每百万 token 几美元时，商业模式的重心将从"用更少的钱做更多的事"转向"用更低的门槛创造新的使用场景"。这可能是 2026 年下半年最值得关注的产业拐点。
